# project-knowledge — start here (for AI agents and new engineers)

Purpose: let you work on DailyTaiyari **without reading the whole repo**. Read the 3 core files, then only the per-app/per-area file you need. These docs were produced by code review of `origin/main` @ `7287616` (2026-11-11 = production) on 2026-11-14; nothing was executed. **Verify against code before relying on a detail; update the doc when you change behaviour.**

> Do not trust the checked-out working tree to represent production — a local branch may be far behind `main`. Check `git log origin/main -1` first.

## Read in this order
1. [`overview.md`](overview.md) — what the product is, stack, repo map, roles, app list.
2. [`architecture.md`](architecture.md) — tenancy, runtime topology, Celery queues, AI layer, sandboxes.
3. [`known-issues.md`](known-issues.md) — ranked security/correctness/ops findings (read before touching payments, auth, quiz, tenancy).

## Conventions for this folder
- Paths are repo-relative. **Never put secret values, real tenant UUIDs, customer emails or credentials in these files** (names of variables only).
- "unverified" = inferred from reading, not run. Remove the tag when you confirm.
- Human runbooks that already exist (don't duplicate): `wiki/*.md`, `.github/skills/{deploy-backend,manage-tenants,populate-data,create-course,post-job}/SKILL.md`.
- When you finish a change, update the matching `backend/<app>.md` section and `known-issues.md` if you fixed/found an issue.
