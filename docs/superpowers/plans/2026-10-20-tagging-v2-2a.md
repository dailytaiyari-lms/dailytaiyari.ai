# Tagging v2 — Plan 2A (Taxonomy, Trees, Tagger v2, Evaluation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat, exam-blind question tagger with a config-driven,
syllabus-tree-bound, two-stage tagger that reports confidence, and measure
its accuracy on a real JEE Main question bank and on real courses.

**Architecture:**
- **Config:** tag vocabulary and exam trees are YAML under
  `backend/intelligence/taxonomy/`, validated and loaded by `sync_taxonomy`.
- **Trees:** syllabus trees are `SyllabusNode` rows per tenant subject. Exam
  trees are instantiated from YAML; custom-course trees are built from
  course Topics plus LLM-proposed subtopics. Every subtopic owns one
  `Concept`, so the existing mastery engine is untouched.
- **Tagger:** a pure core (`tagging_v2.py`) runs locate-then-tag over plain
  data. A DB shell (`tagging_sweep.py`) feeds it and writes `ItemTagging`,
  `ItemSkillTag` and `ConceptLink` rows.
- **Evaluation:** `evaluate_tagger` scores the pure core against JSONL gold
  files.

**Tech Stack:** Django 5 / DRF, PyYAML 6.0.3, SQLite (tests) and Postgres 18
(local production copy), and the Azure OpenAI deployment `gpt-6-luna`
through the existing `chatbot.providers`.

**Spec:** `docs/superpowers/specs/2026-10-19-question-tagging-design.md`
(plus decisions in `2026-10-19-question-tagging-decisions.md`).

## Global Constraints

**Environment**
- Run backend commands from `backend/` with `venv/Scripts/python.exe`. The
  system python has no Django.
- Test command shape:
  `venv/Scripts/python.exe manage.py test <dotted.path> -v 2`.

**Git**
- Work on local branch `feat/tagging-v2`, which is created from
  `feat/response-diagnosis`. Never push.
- Never change git config.
- Stage only the files your task names. Never `git add -A` or `git add .`.
- End every commit message with the `Co-Authored-By:` line given in your
  dispatch.

**Architecture rules**
- Other apps reach the intelligence layer only through
  `intelligence/api.py` and `intelligence/hooks.py`. Do not import
  intelligence models from other apps.
- Inference is recomputed, never incremented. New version constant:
  `TAGGER_V2_PROMPT_VERSION = '2'`. The v1 constant `TAGGER_PROMPT_VERSION`
  stays `'1'` because v1 keeps running for subjects without a tree.
- New models inherit `core.models.TimeStampedModel` (UUID pk, nullable
  `tenant`). Platform-wide rows (`TaxonomyRelease`, `SkillPack`,
  `TagDefinition`) have `tenant = NULL`.
- Item XOR pattern: `question` / `mock_item` with a `CheckConstraint`, as
  `ConceptLink` does. Django's `check=` keyword, matching existing code.

**Tag values**
- Tree levels: `subject` → `sub_subject` → `topic` → `subtopic`. Only the
  last three are `SyllabusNode` rows.
- Node keys are full dotted keys, e.g.
  `jee_main.physics.mechanics.laws_of_motion.friction`. Local key segments
  match `^[a-z0-9][a-z0-9_]*$`.
- Thinking levels (exactly one per item): `recall`, `conceptual`,
  `single_application`, `multi_concept`, `analytical`.
- Compatibility projection onto `cognitive_type`: `recall` → `recall`,
  `multi_concept` → `multi_concept`, any other non-empty value →
  `application`.
- Skill roles: `core` (weight 1.0) and `supporting` (0.5). No limit on
  skills per item.
- Review statuses: `auto`, `needs_review`, `reviewed`. Review reasons:
  `low_confidence`, `invalid_key`, `proposed_subtopic`,
  `stage_disagreement`.
- The default review threshold is `0.6`, stored in
  `TaxonomyRelease.review_confidence_threshold` from `tags.yaml`.
- Tagger limits:
  - batch size 12;
  - question text truncated to 2,000 chars and options to 300 chars, at
    most 8 options;
  - `est_solve_seconds` clamped to 10–1,800;
  - confidence on stage disagreement × 0.8.
- `ConceptLink.tagger_version` is `max_length=60`. Truncate before
  writing.

**Data handling**
- Bank question difficulty is authored and never overwritten. Mock items
  get the model difficulty only while untagged.
- Manual tags (`ItemTagging.source == 'manual'`) are never re-tagged.
- The `eval_jee` dataset is local-only:
  - it lives at `data_dumps/jee_eval/eval_jee.jsonl` and is git-excluded;
  - never commit it, never copy rows into committed files;
  - test fixtures are made-up questions in the dataset's shape.
- Production-copy data (`dt_prod_work`) is real student data. Only question
  text, options and answers may be sent to the LLM, and any file holding it
  goes under `data_dumps/`.

```python
            ItemTagging.objects.create(tenant=self.tenant)

            tenant=self.tenant, question=self.question, thinking_level='recall',
        )
        self.assertEqual(self.question.tagging, tagging)
        self.assertEqual(tagging.review_status, 'auto')

    def test_skill_tag_unique_per_item_and_definition_protected(self):
        skill = TagDefinition.objects.create(
            kind='skill', key='free_body_diagram', label='Free-body diagram', definition='Draw forces.',

        ItemSkillTag.objects.create(tenant=self.tenant, question=self.question, skill=skill, role='core')
        with self.assertRaises(IntegrityError), transaction.atomic():
            ItemSkillTag.objects.create(tenant=self.tenant, question=self.question, skill=skill)

            skill.delete()

    def test_subtopic_node_owns_one_concept(self):
        concept = Concept.objects.create(
            tenant=self.tenant, subject=self.subject, name='Friction', slug='friction', source='syllabus',
```

```python
def _exactly_one_item(name):
    return models.CheckConstraint(
        name=name,
        check=(
            (Q(question__isnull=False) & Q(mock_item__isnull=True))
            | (Q(question__isnull=True) & Q(mock_item__isnull=False))
        ),
    )


class TaxonomyRelease(TimeStampedModel):
    """One synced version of ``taxonomy/tags.yaml`` (platform-wide, tenant NULL).

    The current release is the highest ``sequence``; ``sync_taxonomy`` writes a
    new row only when the file's content changed.
    """

    sequence = models.PositiveIntegerField(unique=True)
    version = models.CharField(max_length=20)
    file_sha256 = models.CharField(max_length=64)
    review_confidence_threshold = models.FloatField(default=0.6)

    class Meta:
        verbose_name = 'Taxonomy Release'
        verbose_name_plural = 'Taxonomy Releases'
        ordering = ['-sequence']

    def __str__(self):
        return f'tags v{self.version} (#{self.sequence})'


class SkillPack(TimeStampedModel):
    """A subject-specific group of skills (physics, programming, …)."""

    key = models.CharField(max_length=50, unique=True)
    label = models.CharField(max_length=100)
    # Subject names/aliases this pack applies to, matched as whole words.
    applies_to = models.JSONField(default=list, blank=True)
    active = models.BooleanField(default=True)

    class Meta:
        verbose_name = 'Skill Pack'
        verbose_name_plural = 'Skill Packs'
        ordering = ['key']

    def __str__(self):
        return self.label


class TagDefinition(TimeStampedModel):
    """One editable tag the v2 tagger may assign (loaded from tags.yaml)."""

    KIND_THINKING = 'thinking_level'
    KIND_SKILL = 'skill'
    KIND_FORMAT = 'special_format'
    KIND_CHOICES = [
        (KIND_THINKING, 'Thinking level'),
        (KIND_SKILL, 'Skill'),
        (KIND_FORMAT, 'Special format'),
    ]

    kind = models.CharField(max_length=20, choices=KIND_CHOICES)
    key = models.CharField(max_length=60)
    label = models.CharField(max_length=120)
    definition = models.TextField()
    pack = models.ForeignKey(
        SkillPack, on_delete=models.SET_NULL, null=True, blank=True, related_name='skills',
    )
    active = models.BooleanField(default=True)
    order = models.PositiveIntegerField(default=0)

    class Meta:
        verbose_name = 'Tag Definition'
        verbose_name_plural = 'Tag Definitions'
        ordering = ['kind', 'order', 'key']
        constraints = [
            models.UniqueConstraint(fields=['kind', 'key'], name='uniq_tag_definition'),
        ]

    def __str__(self):
        return f'{self.kind}:{self.key}'


class SyllabusNode(TimeStampedModel):
    """One node of a subject's syllabus tree (sub-subject, topic or subtopic).

    The subject level is the ``exams.Subject`` itself. Every subtopic owns one
    Concept, so mastery keeps living at the leaves; topic and sub-subject
    figures are rolled up from the tree, never stored as evidence.
    """

    LEVEL_SUB_SUBJECT = 'sub_subject'
    LEVEL_TOPIC = 'topic'
    LEVEL_SUBTOPIC = 'subtopic'
    LEVEL_CHOICES = [
        (LEVEL_SUB_SUBJECT, 'Sub-subject'),
        (LEVEL_TOPIC, 'Topic'),
        (LEVEL_SUBTOPIC, 'Subtopic'),
    ]
    SOURCE_CHOICES = [
        ('exam_tree', 'Exam tree'),
        ('course', 'Course'),
        ('llm_proposed', 'LLM proposed'),
        ('manual', 'Manual'),
    ]
    STATUS_CHOICES = [
        ('active', 'Active'),
        ('proposed', 'Proposed'),
        ('archived', 'Archived'),
    ]

    subject = models.ForeignKey(Subject, on_delete=models.CASCADE, related_name='syllabus_nodes')
    parent = models.ForeignKey(
        'self', on_delete=models.CASCADE, null=True, blank=True, related_name='children',
    )
    level = models.CharField(max_length=12, choices=LEVEL_CHOICES)
    key = models.CharField(max_length=255)
    name = models.CharField(max_length=300)
    description = models.TextField(blank=True, default='')
    # Share within the parent; siblings sum to 1, or are all 0 (unweighted).
    weightage = models.FloatField(default=0.0)
    in_syllabus = models.BooleanField(default=True)
    source = models.CharField(max_length=15, choices=SOURCE_CHOICES, default='course')
    status = models.CharField(max_length=10, choices=STATUS_CHOICES, default='active')
    order = models.PositiveIntegerField(default=0)
    course_topic = models.ForeignKey(
        Topic, on_delete=models.SET_NULL, null=True, blank=True, related_name='syllabus_nodes',
    )
    concept = models.OneToOneField(
        Concept, on_delete=models.SET_NULL, null=True, blank=True, related_name='syllabus_node',
    )

    class Meta:
        verbose_name = 'Syllabus Node'
        verbose_name_plural = 'Syllabus Nodes'
        ordering = ['order', 'name']
        constraints = [
            models.UniqueConstraint(
                fields=['tenant', 'subject', 'key'], name='uniq_syllabus_node_key',
            ),
        ]
        indexes = [models.Index(fields=['subject', 'level', 'status'])]

    def __str__(self):
        return f'{self.level}:{self.key}'


class CourseSyllabus(TimeStampedModel):
    """How a course is tagged: against an exam tree, or its own built tree."""

    course = models.OneToOneField(Course, on_delete=models.CASCADE, related_name='syllabus')
    exam_tree = models.CharField(max_length=40, blank=True, default='')
    audience = models.CharField(max_length=200, blank=True, default='')
    # {subject_id: tree_subject_key} for exam-mapped courses.
    subject_map = models.JSONField(default=dict, blank=True)
    # {subject_id: [pack_key, …]} — explicit packs; unlisted subjects fall
    # back to SkillPack.applies_to name matching.
    skill_packs = models.JSONField(default=dict, blank=True)

    class Meta:
        verbose_name = 'Course Syllabus'
        verbose_name_plural = 'Course Syllabi'

    def __str__(self):
        return f'{self.course_id} → {self.exam_tree or "course tree"}'


class ItemTagging(TimeStampedModel):
    """The v2 tag set for one assessment item (bank Question or MockTestItem)."""

    REVIEW_AUTO = 'auto'
    REVIEW_NEEDED = 'needs_review'
    REVIEW_DONE = 'reviewed'
    REVIEW_CHOICES = [
        (REVIEW_AUTO, 'Auto-accepted'),
        (REVIEW_NEEDED, 'Needs review'),
        (REVIEW_DONE, 'Reviewed'),
    ]
    SOURCE_CHOICES = [
        ('llm_tagger', 'LLM tagger'),
        ('generator', 'Generator'),
        ('manual', 'Manual'),
    ]

    question = models.OneToOneField(
        'quiz.Question', on_delete=models.CASCADE, null=True, blank=True, related_name='tagging',
    )
    mock_item = models.OneToOneField(
        'quiz.MockTestItem', on_delete=models.CASCADE, null=True, blank=True, related_name='tagging',
    )
    primary_node = models.ForeignKey(
        SyllabusNode, on_delete=models.SET_NULL, null=True, blank=True, related_name='primary_items',
    )
    secondary_nodes = models.ManyToManyField(SyllabusNode, blank=True, related_name='secondary_items')
    thinking_level = models.CharField(max_length=30, blank=True, default='')
    special_format = models.CharField(max_length=30, blank=True, default='')
    difficulty_prior = models.CharField(max_length=10, blank=True, default='')
    est_solve_seconds = models.PositiveIntegerField(null=True, blank=True)
    confidence = models.FloatField(default=0.0)
    review_status = models.CharField(max_length=15, choices=REVIEW_CHOICES, default=REVIEW_AUTO)
    review_reasons = models.JSONField(default=list, blank=True)
    proposed_subtopic = models.CharField(max_length=300, blank=True, default='')
    source = models.CharField(max_length=15, choices=SOURCE_CHOICES, default='llm_tagger')
    tagger_version = models.CharField(max_length=120, blank=True, default='')
    taxonomy_version = models.CharField(max_length=20, blank=True, default='')
    tree_version = models.CharField(max_length=64, blank=True, default='')
    raw = models.JSONField(default=dict, blank=True)

    class Meta:
        verbose_name = 'Item Tagging'
        verbose_name_plural = 'Item Taggings'
        constraints = [_exactly_one_item('itemtagging_exactly_one_item')]
        indexes = [models.Index(fields=['tenant', 'review_status'])]

    def __str__(self):
        return f'tagging {self.question_id or self.mock_item_id}'


class ItemSkillTag(TimeStampedModel):
    """One skill an item exercises, core (weight 1.0) or supporting (0.5)."""

    ROLE_CORE = 'core'
    ROLE_SUPPORTING = 'supporting'
    ROLE_CHOICES = [(ROLE_CORE, 'Core'), (ROLE_SUPPORTING, 'Supporting')]

    question = models.ForeignKey(
        'quiz.Question', on_delete=models.CASCADE, null=True, blank=True, related_name='skill_tags',
    )
    mock_item = models.ForeignKey(
        'quiz.MockTestItem', on_delete=models.CASCADE, null=True, blank=True, related_name='skill_tags',
    )
    skill = models.ForeignKey(TagDefinition, on_delete=models.PROTECT, related_name='item_tags')
    role = models.CharField(max_length=12, choices=ROLE_CHOICES, default=ROLE_SUPPORTING)
    reason = models.CharField(max_length=200, blank=True, default='')
    source = models.CharField(max_length=15, choices=ItemTagging.SOURCE_CHOICES, default='llm_tagger')

    class Meta:
        verbose_name = 'Item Skill Tag'
        verbose_name_plural = 'Item Skill Tags'
        constraints = [
            _exactly_one_item('itemskilltag_exactly_one_item'),
            models.UniqueConstraint(
                fields=['skill', 'question'], condition=Q(question__isnull=False),
                name='uniq_skilltag_question',
            ),
            models.UniqueConstraint(
                fields=['skill', 'mock_item'], condition=Q(mock_item__isnull=False),
                name='uniq_skilltag_mock_item',
            ),
        ]

    def __str__(self):
        return f'{self.skill_id} on {self.question_id or self.mock_item_id}'
```

```python
"""Tag vocabulary and exam syllabus trees: YAML config → validated data → DB.

The YAML files under ``intelligence/taxonomy/`` are the source of truth
(decision D4). Validation runs before any write and reports every problem at
once. Nothing is ever deleted: a key that disappears from the file is
deactivated, so existing tags keep their meaning.
"""
import hashlib
import re
import uuid

import yaml
from django.db import transaction
from django.db.models import Max

KEY_RE = re.compile(r'^[a-z0-9][a-z0-9_]*$')
TREE_LEVELS = ('subject', 'sub_subject', 'topic', 'subtopic')
WEIGHT_TOLERANCE = 0.02
DEFAULT_REVIEW_THRESHOLD = 0.6


class TaxonomyError(ValueError):
    """Invalid taxonomy YAML; ``errors`` lists every problem found."""

    def __init__(self, errors):
        self.errors = list(errors)
        super().__init__('; '.join(self.errors))


def read_yaml(path):
    """(parsed data, sha256 of the file text)."""
    with open(path, encoding='utf-8') as handle:
        text = handle.read()
    return yaml.safe_load(text) or {}, hashlib.sha256(text.encode('utf-8')).hexdigest()


def _text(value):
    return str(value if value is not None else '').strip()


def _entries(raw, where, errors, seen=None):
    """Validate a list of {key, label, definition[, active]} entries."""
    seen = set() if seen is None else seen
    if not isinstance(raw, list):
        errors.append(f'{where}: must be a list')
        return []
    clean = []
    for index, entry in enumerate(raw):
        if not isinstance(entry, dict):
            errors.append(f'{where}[{index}]: must be a mapping')
            continue
        key = entry.get('key')
        if not isinstance(key, str) or not KEY_RE.match(key):
            errors.append(f'{where}[{index}]: key {key!r} must be lower_snake_case')
            continue
        if key in seen:
            errors.append(f'{where}.{key}: duplicate key')
            continue
        seen.add(key)
        for field in ('label', 'definition'):
            if not _text(entry.get(field)):
                errors.append(f'{where}.{key}: {field} is required')
        clean.append({
            'key': key,
            'label': _text(entry.get('label')),
            'definition': _text(entry.get('definition')),
            'active': entry.get('active', True) is not False,
        })
    return clean


def validate_tags(data):
    """Validate parsed tags.yaml. Returns the normalized vocabulary or raises."""
    if not isinstance(data, dict):
        raise TaxonomyError(['tags.yaml: the top level must be a mapping'])
    errors = []
    if not _text(data.get('version')):
        errors.append('version is required')
    threshold = data.get('review_confidence_threshold', DEFAULT_REVIEW_THRESHOLD)
    if isinstance(threshold, bool) or not isinstance(threshold, (int, float)) or not 0 < threshold < 1:
        errors.append('review_confidence_threshold must be a number between 0 and 1')
        threshold = DEFAULT_REVIEW_THRESHOLD
    thinking = _entries(data.get('thinking_levels') or [], 'thinking_levels', errors)
    if not thinking:
        errors.append('thinking_levels must not be empty')
    formats = _entries(data.get('special_formats') or [], 'special_formats', errors)

    skills = data.get('skills') or {}
    if not isinstance(skills, dict):
        errors.append('skills: must be a mapping with universal and packs')
        skills = {}
    skill_keys = set()  # unique across universal and every pack
    universal = _entries(skills.get('universal') or [], 'skills.universal', errors, skill_keys)
    packs, pack_keys = [], set()
    for index, pack in enumerate(skills.get('packs') or []):
        where = f'skills.packs[{index}]'
        if not isinstance(pack, dict):
            errors.append(f'{where}: must be a mapping')
            continue
        key = pack.get('key')
        if not isinstance(key, str) or not KEY_RE.match(key) or key in pack_keys:
            errors.append(f'{where}: key {key!r} must be unique lower_snake_case')
            continue
        pack_keys.add(key)
        applies_to = [_text(name) for name in pack.get('applies_to') or [] if _text(name)]
        if not applies_to:
            errors.append(f'skills.packs.{key}: applies_to must list at least one subject name')
        if not _text(pack.get('label')):
            errors.append(f'skills.packs.{key}: label is required')
        packs.append({
            'key': key,
            'label': _text(pack.get('label')),
            'applies_to': applies_to,
            'active': pack.get('active', True) is not False,
            'skills': _entries(pack.get('skills') or [], f'skills.packs.{key}.skills', errors, skill_keys),
        })
    if errors:
        raise TaxonomyError(errors)
    return {
        'version': _text(data.get('version')),
        'review_confidence_threshold': float(threshold),
        'thinking_levels': thinking,
        'special_formats': formats,
        'universal_skills': universal,
        'packs': packs,
    }


def _tree_level(raw, depth, path, errors):
    level = TREE_LEVELS[depth]
    if not isinstance(raw, list) or not raw:
        errors.append(f'{path}: needs a non-empty list of {level} nodes')
        return []
    clean, seen, weights = [], set(), []
    for index, node in enumerate(raw):
        if not isinstance(node, dict):
            errors.append(f'{path}[{index}]: must be a mapping')
            continue
        key = node.get('key')
        if not isinstance(key, str) or not KEY_RE.match(key):
            errors.append(f'{path}[{index}]: key {key!r} must be lower_snake_case')
            continue
        if key in seen:
            errors.append(f'{path}.{key}: duplicate key')
            continue
        seen.add(key)
        if not _text(node.get('label')):
            errors.append(f'{path}.{key}: label is required')
        weight = node.get('weightage', 0)
        if isinstance(weight, bool) or not isinstance(weight, (int, float)) or weight < 0:
            errors.append(f'{path}.{key}: weightage must be a number >= 0')
            weight = 0
        weights.append(float(weight))
        entry = {
            'key': key,
            'label': _text(node.get('label')),
            'description': _text(node.get('description')),
            'weightage': float(weight),
            'in_syllabus': node.get('in_syllabus', True) is not False,
            'aliases': [_text(alias) for alias in node.get('aliases') or [] if _text(alias)],
        }
        if depth + 1 < len(TREE_LEVELS):
            entry['children'] = _tree_level(node.get('children'), depth + 1, f'{path}.{key}', errors)
        elif node.get('children'):
            errors.append(f'{path}.{key}: subtopics cannot have children')
        clean.append(entry)
    total = sum(weights)
    if total and abs(total - 1.0) > WEIGHT_TOLERANCE:
        errors.append(f'{path}: {level} weightages sum to {total:.3f}; expected 1 (or all 0)')
    return clean


def validate_exam_tree(data):
    """Validate a parsed exam tree YAML. Returns the normalized tree or raises."""
    if not isinstance(data, dict):
        raise TaxonomyError(['exam tree: the top level must be a mapping'])
    errors = []
    key = data.get('key')
    if not isinstance(key, str) or not KEY_RE.match(key):
        errors.append(f'key {key!r} must be lower_snake_case')
        key = '?'
    for field in ('label', 'audience', 'version'):
        if not _text(data.get(field)):
            errors.append(f'{field} is required')
    subjects = _tree_level(data.get('subjects'), 0, key, errors)
    if errors:
        raise TaxonomyError(errors)
    return {
        'key': key,
        'label': _text(data.get('label')),
        'audience': _text(data.get('audience')),
        'version': _text(data.get('version')),
        'subjects': subjects,
    }


def flatten_tree(tree):
    """Every node of a validated tree in pre-order, with full dotted keys.

    ``in_syllabus`` is inherited: a node under an out-of-syllabus parent is
    out of syllabus too.
    """
    flat = []

    def walk(nodes, depth, parent_key, subject_key, parent_in_syllabus):
        for order, node in enumerate(nodes):
            key = f'{parent_key}.{node["key"]}'
            subject = subject_key or node['key']
            in_syllabus = parent_in_syllabus and node['in_syllabus']
            flat.append({
                'key': key,
                'local_key': node['key'],
                'level': TREE_LEVELS[depth],
                'parent_key': parent_key,
                'subject': subject,
                'label': node['label'],
                'description': node['description'],
                'weightage': node['weightage'],
                'in_syllabus': in_syllabus,
                'aliases': node['aliases'],
                'order': order,
            })
            walk(node.get('children') or [], depth + 1, key, subject, in_syllabus)

    walk(tree['subjects'], 0, tree['key'], None, True)
    return flat

def load_exam_tree(exam_key):
    """The validated tree from ``taxonomy/exams/<exam_key>.yaml``."""

@transaction.atomic
def sync_vocabulary(tags, file_sha256):
    """Upsert a validated vocabulary. Never deletes; missing keys deactivate."""
    from intelligence.models import SkillPack, TagDefinition, TaxonomyRelease

    summary = {'upserted': 0, 'deactivated': 0, 'release': None}
    kept = {
        TagDefinition.KIND_THINKING: set(),
        TagDefinition.KIND_FORMAT: set(),
        TagDefinition.KIND_SKILL: set(),
    }

    def upsert(kind, entry, order, pack=None):
        TagDefinition.objects.update_or_create(
            kind=kind, key=entry['key'],
            defaults={
                'tenant': None, 'label': entry['label'], 'definition': entry['definition'],
                'active': entry['active'], 'pack': pack, 'order': order,
            },
        )
        kept[kind].add(entry['key'])
        summary['upserted'] += 1

    for order, entry in enumerate(tags['thinking_levels']):
        upsert(TagDefinition.KIND_THINKING, entry, order)
    for order, entry in enumerate(tags['special_formats']):
        upsert(TagDefinition.KIND_FORMAT, entry, order)
    for order, entry in enumerate(tags['universal_skills']):
        upsert(TagDefinition.KIND_SKILL, entry, order)
    pack_keys = set()
    for pack_index, pack in enumerate(tags['packs'], start=1):
        pack_row, _ = SkillPack.objects.update_or_create(
            key=pack['key'],
            defaults={
                'tenant': None, 'label': pack['label'],
                'applies_to': pack['applies_to'], 'active': pack['active'],
            },
        )
        pack_keys.add(pack['key'])
        for order, entry in enumerate(pack['skills']):
            upsert(TagDefinition.KIND_SKILL, entry, pack_index * 1000 + order, pack=pack_row)

    for kind, keys in kept.items():
        summary['deactivated'] += (
            TagDefinition.objects.filter(kind=kind, active=True).exclude(key__in=keys)
            .update(active=False)
        )
    SkillPack.objects.filter(active=True).exclude(key__in=pack_keys).update(active=False)

    latest = current_release()
    if latest is None or latest.file_sha256 != file_sha256:
        sequence = (TaxonomyRelease.objects.aggregate(top=Max('sequence'))['top'] or 0) + 1
        summary['release'] = TaxonomyRelease.objects.create(
            tenant=None, sequence=sequence, version=tags['version'], file_sha256=file_sha256,
            review_confidence_threshold=tags['review_confidence_threshold'],
        )
    return summary


def mark_subjects_stale(subject_ids):
    """Flip tagged items of these subjects to 'stale' so the sweep re-tags them."""
    from quiz.models import MockTestItem, Question

    ids = []
    for raw in subject_ids:
        try:
            ids.append(uuid.UUID(str(raw)))
        except ValueError as exc:
            raise TaxonomyError([f'not a subject id: {raw!r}']) from exc
    marked = Question.objects.filter(subject_id__in=ids, tagging_status='tagged').update(
        tagging_status='stale')
    marked += MockTestItem.objects.filter(subject_id__in=ids, tagging_status='tagged').update(
        tagging_status='stale')
    return marked
```

```python
"""Validate intelligence/taxonomy/*.yaml and load the tag vocabulary.

    manage.py sync_taxonomy --check            # validate only (CI)
    manage.py sync_taxonomy                    # load tags.yaml into the DB
    manage.py sync_taxonomy --retag-subjects <id,id>

from django.core.management.base import BaseCommand, CommandError

from intelligence.services.taxonomy import (
    TaxonomyError, load_exam_tree, load_tags, mark_subjects_stale, shipped_exam_keys,
    sync_vocabulary,
)


class Command(BaseCommand):
    help = 'Validate the taxonomy YAML files and load the tag vocabulary into the database.'

    def add_arguments(self, parser):
        parser.add_argument('--check', action='store_true', help='Validate only; write nothing.')
        parser.add_argument('--retag-subjects', default='',
                            help='Comma-separated subject ids whose tagged items become stale.')

    def handle(self, *args, **options):
        try:
            tags, sha = load_tags()
            trees = [load_exam_tree(key) for key in shipped_exam_keys()]
        except TaxonomyError as exc:
            raise CommandError('Taxonomy is invalid:\n- ' + '\n- '.join(exc.errors)) from exc
        tree_names = ', '.join(tree['key'] for tree in trees) or 'none'
        self.stdout.write(f'tags.yaml v{tags["version"]} OK; exam trees OK: {tree_names}')
        if options['check']:
            return

        summary = sync_vocabulary(tags, sha)
        release = summary['release']
        self.stdout.write(
            f'{summary["upserted"]} tag(s) upserted, {summary["deactivated"]} deactivated; '
            + (f'new release #{release.sequence}' if release else 'no content change')
        )
        subject_ids = [raw.strip() for raw in options['retag_subjects'].split(',') if raw.strip()]
        if subject_ids:
            try:
                marked = mark_subjects_stale(subject_ids)
            except TaxonomyError as exc:
                raise CommandError('; '.join(exc.errors)) from exc
            self.stdout.write(f'{marked} item(s) marked stale for re-tagging')
        elif release:
            self.stdout.write('To re-tag existing items, run again with --retag-subjects <ids>.')
```

```python
    with open(path, encoding='utf-8') as handle:

def node_key(slug):
    """'calculation-of-standard-deviation,-variance' → 'calculation_of_standard_deviation_variance'."""
    return re.sub(r'[^a-z0-9]+', '_', (slug or '').casefold()).strip('_')


def slug_label(slug):
    """'ac-circuits-and-power-in-ac-circuits' → 'AC Circuits and Power in AC Circuits'."""
    words = (slug or '').replace(',-', ', ').replace('-', ' ').split()
    out = []
    for index, word in enumerate(words):
        bare, comma = (word[:-1], ',') if word.endswith(',') else (word, '')
        if bare in ACRONYMS or re.fullmatch(r'\d+d', bare):
            bare = bare.upper()
        elif index and bare in SMALL_WORDS:
            pass
        else:
            bare = bare[:1].upper() + bare[1:]
        out.append(bare + comma)
    return ' '.join(out)


def paper_year(paper_id):
    match = re.search(r'(20\d\d)', paper_id or '')
    return int(match.group(1)) if match else 0


def has_image(row):
    return bool(IMAGE_RE.search((row.get('question') or '') + (row.get('options') or '')))


def strip_html(text):
    """Tags out, entities decoded, whitespace collapsed; LaTeX is kept."""
    return ' '.join(html.unescape(TAG_RE.sub(' ', text or '')).split())


def parse_options(row):
    try:
        options = json.loads(row.get('options') or '[]')
    except (TypeError, ValueError):
        return []
    if not isinstance(options, list):
        return []
    return [
        {'id': str(option.get('identifier') or ''), 'text': strip_html(str(option.get('content') or ''))}
        for option in options if isinstance(option, dict)
    ]


def correct_ids(row):
    try:
        value = json.loads(row.get('correct_option') or '[]')
    except (TypeError, ValueError):
        return []
    return [str(item) for item in value] if isinstance(value, list) else []


def is_usable(row, out_of_syllabus=frozenset()):
    """Text-only, 2021+, a known type, in syllabus, with an answer."""
    if row.get('question_type') not in TYPE_MAP or row.get('subject') not in SUBJECT_LABELS:
        return False
    if paper_year(row.get('paper_id')) < POOL_MIN_YEAR or has_image(row):
        return False
    if node_key(row.get('chapter')) in out_of_syllabus:
        return False
    if row['question_type'] == 'integer':
        return str(row.get('answer') or '').strip() != ''
    ids = {option['id'] for option in parse_options(row)}
    return len(ids) >= 2 and bool(correct_ids(row)) and set(correct_ids(row)) <= ids


def row_to_payload(row):
    """The tagger payload for one dataset row (answer as text)."""
    options = parse_options(row)
    if row.get('question_type') == 'integer':
        answer = str(row.get('answer') or '').strip()
    else:
        wanted = set(correct_ids(row))
        answer = ' | '.join(option['text'] for option in options if option['id'] in wanted)
    return {
        'id': str(row['question_id']),
        'type': TYPE_MAP.get(row.get('question_type'), ''),
        'question': strip_html(row.get('question')),
        'options': [option['text'] for option in options],
        'answer': answer,
    }


def stratified_sample(rows, n, seed):
    """Deterministic sample: equal share per subject, round-robin over chapters."""
    rng = random.Random(seed)
    by_subject = defaultdict(lambda: defaultdict(list))
    for item in sorted(rows, key=lambda r: str(r['question_id'])):
        by_subject[item['subject']][item['chapter']].append(item)
    subjects = sorted(by_subject)
    if not subjects or n <= 0:
        return []
    picked = []
    for position, subject in enumerate(subjects):
        quota = n // len(subjects) + (1 if position < n % len(subjects) else 0)
        chapters = by_subject[subject]
        for bucket in chapters.values():
            rng.shuffle(bucket)
        order = sorted(chapters)
        cursor = {chapter: 0 for chapter in order}
        taken = []
        while len(taken) < quota and any(cursor[c] < len(chapters[c]) for c in order):
            for chapter in order:
                if len(taken) >= quota:
                    break
                if cursor[chapter] < len(chapters[chapter]):
                    taken.append(chapters[chapter][cursor[chapter]])
                    cursor[chapter] += 1
        picked.extend(taken)
    return picked


def _share(part, whole):
    return round(part / whole, 4) if whole else 0.0


def draft_jee_main_tree(rows):
    """Build the jee_main tree (``validate_exam_tree`` input) from dataset rows.

    Weightage is each node's share of 2021+ questions within its parent;
    out-of-syllabus chapters (and their subtopics) weigh 0. Returns
    ``(tree, warnings)``; raises ValueError for chapters missing from
    JEE_MAIN_GROUPS.
    """
    chapters = defaultdict(lambda: defaultdict(set))
    recent = Counter()
    for item in rows:
        subject, chapter, topic = item.get('subject'), item.get('chapter'), item.get('topic')
        if subject not in JEE_MAIN_GROUPS or not chapter or not topic:
            continue
        chapters[subject][chapter].add(topic)
        if paper_year(item.get('paper_id')) >= POOL_MIN_YEAR:
            recent[(subject, chapter, topic)] += 1

    grouped = {s: {c for _, _, slugs in groups for c in slugs} for s, groups in JEE_MAIN_GROUPS.items()}
    missing = sorted(f'{s}/{c}' for s in chapters for c in chapters[s] if c not in grouped[s])
    if missing:
        raise ValueError('chapters missing from JEE_MAIN_GROUPS: ' + ', '.join(missing))
    warnings = sorted(f'{s}/{c}' for s in grouped for c in grouped[s] if c not in chapters.get(s, {}))

    def counted(subject, chapter, topic=None):
        if chapter in JEE_MAIN_OUT_OF_SYLLABUS:
            return 0
        if topic is not None:
            return recent[(subject, chapter, topic)]
        return sum(n for (s, c, _), n in recent.items() if s == subject and c == chapter)

    subjects = []
    for subject, groups in JEE_MAIN_GROUPS.items():
        present_by_group = [(key, label, [c for c in slugs if c in chapters.get(subject, {})])
                            for key, label, slugs in groups]
        subject_total = sum(counted(subject, c) for _, _, present in present_by_group for c in present)
        group_nodes = []
        for group_key, group_label, present in present_by_group:
            if not present:
                continue
            group_total = sum(counted(subject, c) for c in present)
            topic_nodes = []
            for chapter in present:
                chapter_total = counted(subject, chapter)
                children, used = [], set()
                for topic in sorted(chapters[subject][chapter]):
                    key, suffix = node_key(topic), 2
                    while key in used:  # two slugs that normalise to one key
                        key, suffix = f'{node_key(topic)}_{suffix}', suffix + 1
                    used.add(key)
                    children.append({
                        'key': key, 'label': slug_label(topic),
                        'weightage': _share(counted(subject, chapter, topic), chapter_total),
                        'aliases': [topic],
                    })
                topic_nodes.append({
                    'key': node_key(chapter),
                    'label': LABEL_OVERRIDES.get(chapter) or slug_label(chapter),
                    'weightage': _share(chapter_total, group_total),
                    'in_syllabus': chapter not in JEE_MAIN_OUT_OF_SYLLABUS,
                    'aliases': [chapter],
                    'children': children,
                })
            group_nodes.append({
                'key': group_key, 'label': group_label,
                'weightage': _share(group_total, subject_total), 'children': topic_nodes,
            })
        if group_nodes:
            subjects.append({
                'key': subject, 'label': SUBJECT_LABELS[subject], 'aliases': SUBJECT_ALIASES[subject],
                'weightage': 0.0, 'children': group_nodes,
            })
    for subject_node in subjects:
        subject_node['weightage'] = _share(1, len(subjects))
    tree = {
        'key': 'jee_main', 'label': 'JEE Main', 'audience': TREE_AUDIENCE, 'version': 1,
        'subjects': subjects,
    }
    return tree, warnings


def tree_key_index(tree):
    """Map dataset slugs to full tree keys, via each node's slug alias.

    ``(subject, chapter_slug) → topic key`` and
    ``(subject, chapter_slug, topic_slug) → subtopic key``.
    """
    index = {}
    for subject in tree['subjects']:
        for group in subject['children']:
            for topic in group['children']:
                topic_key = f'{tree["key"]}.{subject["key"]}.{group["key"]}.{topic["key"]}'
                for chapter_slug in topic['aliases'] or [topic['key']]:
                    index[(subject['key'], chapter_slug)] = topic_key
                    for subtopic in topic['children']:
                        for topic_slug in subtopic['aliases'] or [subtopic['key']]:
                            index[(subject['key'], chapter_slug, topic_slug)] = f'{topic_key}.{subtopic["key"]}'
    return index


def out_of_syllabus_chapters(tree):
    """Local keys of topic-level nodes marked out of syllabus."""
    return frozenset(
        topic['key']
        for subject in tree['subjects'] for group in subject['children'] for topic in group['children']
        if not topic['in_syllabus']
    )
```

```python
"""Dev only: draft taxonomy/exams/jee_main.yaml from the local eval_jee dataset.

    manage.py draft_exam_tree --from-eval-jee ../data_dumps/jee_eval/eval_jee.jsonl

The output holds syllabus names and weights only (no question content). Review
it by hand — labels, merged duplicates, the sub-subject grouping — then run
``sync_taxonomy --check`` and commit it.
"""
from pathlib import Path

import yaml
from django.core.management.base import BaseCommand, CommandError

from intelligence.services.eval_jee import draft_jee_main_tree, read_rows
from intelligence.services.taxonomy import TaxonomyError, flatten_tree, validate_exam_tree
from intelligence.taxonomy import EXAMS_DIR

HEADER = """\
# JEE Main syllabus tree (decision D5): subject → sub-subject → topic → subtopic.
# Drafted by `manage.py draft_exam_tree` from the chapter/topic labels of the
# local-only eval_jee dataset, then reviewed by hand. No question content.
# weightage = share of 2021–2024 JEE Main questions within the parent node.
# in_syllabus: false marks chapters removed from the NTA JEE Main syllabus (2024).
# aliases = the dataset's slugs (used to build gold files and to link course topics).
"""


class Command(BaseCommand):
    help = 'Draft the JEE Main exam tree YAML from the local eval_jee dataset (dev only).'

    def add_arguments(self, parser):
        parser.add_argument('--from-eval-jee', required=True, dest='source',
                            help='Path to eval_jee.jsonl (local only, never committed).')
        parser.add_argument('--out', default=str(EXAMS_DIR / 'jee_main.yaml'))

    def handle(self, *args, **options):
        source = Path(options['source'])
        if not source.exists():
            raise CommandError(f'{source} not found.')
        try:
            tree, warnings = draft_jee_main_tree(read_rows(source))
            flat = flatten_tree(validate_exam_tree(tree))
        except (ValueError, TaxonomyError) as exc:
            raise CommandError(str(exc)) from exc
        out = Path(options['out'])
        out.parent.mkdir(parents=True, exist_ok=True)
        out.write_text(
            HEADER + yaml.safe_dump(tree, sort_keys=False, allow_unicode=True, width=100),
            encoding='utf-8',
        )
        for warning in warnings:
            self.stderr.write(f'warning: grouped chapter has no questions in the data: {warning}')
        levels = {level: sum(1 for node in flat if node['level'] == level)
                  for level in ('subject', 'sub_subject', 'topic', 'subtopic')}
        out_of_syllabus = sum(1 for node in flat if node['level'] == 'topic' and not node['in_syllabus'])
        self.stdout.write(self.style.SUCCESS(
            f'Wrote {out}: {levels} ({out_of_syllabus} topic(s) out of syllabus).'))
```

```python
- Exam trees (YAML) are *instantiated* per course subject, keyed by their

- Every subtopic node owns one Concept: mastery keeps living at the leaves.

  the v2 tagger consumes (see services/tagging_v2.py).

import hashlib

import re

from django.db.models import Q
from django.utils.text import slugify

def norm(text):
    return ' '.join(re.sub(r'[^a-z0-9]+', ' ', (text or '').casefold()).split())


def pack_matches(applies_to, names):
    """True when any ``applies_to`` term occurs as whole words in any name."""
    haystacks = [f' {norm(name)} ' for name in names if norm(name)]
    return any(f' {norm(term)} ' in haystack for term in applies_to if norm(term) for haystack in haystacks)


def _node_concept_slug(key):
    slug = slugify(key.replace('.', ' '))
    if len(slug) > 220:
        slug = f'{slug[:200]}-{hashlib.sha1(key.encode()).hexdigest()[:12]}'
    return slug


def ensure_node_concept(node):
    """Give a subtopic node its own Concept (created once, renamed on re-sync)."""
    from intelligence.models import Concept

    if node.concept_id:
        concept = node.concept
        if concept.name != node.name[:200]:
            concept.name = node.name[:200]
            concept.save(update_fields=['name', 'updated_at'])
        return concept
    concept, _ = Concept.objects.get_or_create(
        tenant=node.tenant, subject=node.subject, slug=_node_concept_slug(node.key),
        defaults={'name': node.name[:200], 'source': 'syllabus'},
    )
    node.concept = concept
    node.save(update_fields=['concept', 'updated_at'])
    anchor = node.parent.course_topic if node.parent_id else None
    if anchor is not None:
        concept.topics.add(anchor)
    return concept


def compute_tree_version(subject):
    """Hash of the subject's live tree; part of the tagging cache key."""
    from intelligence.models import SyllabusNode

    rows = list(
        SyllabusNode.objects.filter(subject=subject).exclude(status='archived').order_by('key')
        .values_list('key', 'name', 'description', 'level', 'in_syllabus')
    )
    return hashlib.sha256(json.dumps(rows, ensure_ascii=False).encode('utf-8')).hexdigest()[:16]


def _link_course_topics(subject, nodes, aliases, unmatched):
    from exams.models import Topic

    topics = list(Topic.objects.filter(subject=subject).order_by('order', 'name'))
    by_name = {}
    for topic in topics:
        by_name.setdefault(norm(topic.name), topic)
        by_name.setdefault(norm(topic.code), topic)
    linked_ids, linked = set(), 0
    for key, node in nodes.items():
        if node.level != 'topic':
            continue
        candidates = [node.name, key.rsplit('.', 1)[-1], *aliases.get(key, [])]
        match = next((by_name[norm(c)] for c in candidates if norm(c) in by_name), None)
        if match is None:
            continue
        if node.course_topic_id != match.id:
            node.course_topic = match
            node.save(update_fields=['course_topic', 'updated_at'])
        linked_ids.add(match.id)
        linked += 1
    unmatched.extend(f'{subject.name}: {topic.name}' for topic in topics if topic.id not in linked_ids)
    return linked


def _merge_existing_concepts(subject, summary):
    """Fold pre-tree flat Concepts into tree subtopics with the same name."""
    from intelligence.models import Concept, SyllabusNode

    by_slug = {}
    owned = set()
    for node in SyllabusNode.objects.filter(subject=subject, level='subtopic', status='active'):
        if node.concept_id:
            owned.add(node.concept_id)
            by_slug.setdefault(concept_slug(node.name), []).append(node)
    for concept in Concept.objects.filter(subject=subject, status='active').exclude(id__in=owned):
        matches = by_slug.get(concept.slug) or by_slug.get(concept_slug(concept.name)) or []
        if len(matches) == 1:
            merge_concept(concept, matches[0].concept)
            summary['merged_concepts'] += 1
        elif len(matches) > 1:
            summary['ambiguous_concepts'].append(f'{subject.name}: {concept.name}')


@transaction.atomic
def instantiate_exam_tree(course, exam_key, subject_map, *, audience=None):
    """Upsert an exam tree's nodes under each mapped course subject.

    ``subject_map`` is ``{tree_subject_key: exams.Subject}``. Updates by key,
    never deletes: nodes missing from the tree become 'archived'.
    """
    from intelligence.models import CourseSyllabus, SyllabusNode

    tree = load_exam_tree(exam_key)
    flat = flatten_tree(tree)
    tree_subjects = {node['subject'] for node in flat}
    unknown = sorted(set(subject_map) - tree_subjects)
    if unknown:
        raise TaxonomyError([f'{exam_key} has no subject {key!r}' for key in unknown])

    record, _ = CourseSyllabus.objects.get_or_create(course=course, defaults={'tenant': course.tenant})
    record.exam_tree = exam_key
    record.audience = (audience or tree['audience'])[:200]
    record.subject_map = {str(subject.id): key for key, subject in subject_map.items()}
    record.save()

    summary = {'created': 0, 'updated': 0, 'archived': 0, 'linked_topics': 0,
               'unmatched_topics': [], 'merged_concepts': 0, 'ambiguous_concepts': []}
    for tree_subject, subject in subject_map.items():
        entries = [node for node in flat if node['subject'] == tree_subject and node['level'] != 'subject']
        nodes = {}
        for entry in entries:  # pre-order: parents before children
            node, created = SyllabusNode.objects.update_or_create(
                tenant=course.tenant, subject=subject, key=entry['key'],
                defaults={
                    'parent': nodes.get(entry['parent_key']),
                    'level': entry['level'],
                    'name': entry['label'][:300],
                    'description': entry['description'],
                    'weightage': entry['weightage'],
                    'in_syllabus': entry['in_syllabus'],
                    'source': 'exam_tree',
                    'status': 'active',
                    'order': entry['order'],
                },
            )
            nodes[entry['key']] = node
            summary['created' if created else 'updated'] += 1
        summary['archived'] += (
            SyllabusNode.objects.filter(subject=subject, source='exam_tree')
            .exclude(key__in=list(nodes)).exclude(status='archived').update(status='archived')
        )
        aliases = {entry['key']: entry['aliases'] for entry in entries}
        summary['linked_topics'] += _link_course_topics(subject, nodes, aliases, summary['unmatched_topics'])
        for node in nodes.values():
            if node.level == 'subtopic':
                node.refresh_from_db(fields=['course_topic', 'concept'])
                ensure_node_concept(node)
        _merge_existing_concepts(subject, summary)
    return summary


def packs_for_subject(subject):
    """Explicit CourseSyllabus packs, else whole-word name matching."""
    from intelligence.models import CourseSyllabus, SkillPack

    active = {pack.key: pack for pack in SkillPack.objects.filter(active=True).order_by('key')}
    record = CourseSyllabus.objects.filter(course_id=subject.course_id).first()
    if record and str(subject.id) in (record.skill_packs or {}):
        return [active[key] for key in record.skill_packs[str(subject.id)] if key in active]
    names = [subject.name, subject.code]
    if record and record.subject_map.get(str(subject.id)):
        names.append(record.subject_map[str(subject.id)])
    return [pack for pack in active.values() if pack_matches(pack.applies_to, names)]


def _definitions(kind, packs=None):
    from intelligence.models import TagDefinition

    rows = TagDefinition.objects.filter(kind=kind, active=True).select_related('pack')
    if kind == TagDefinition.KIND_SKILL:
        rows = rows.filter(Q(pack__isnull=True) | Q(pack__in=packs or []))
        return [{'key': r.key, 'label': r.label, 'definition': r.definition,
                 'pack': r.pack.key if r.pack_id else ''} for r in rows]
    return [{'key': r.key, 'label': r.label, 'definition': r.definition} for r in rows]

def tagging_context(subject):
    """The v2 tagger context for one subject, built from the database."""
    from intelligence.models import CourseSyllabus, SyllabusNode, TagDefinition

    course = subject.course
    record = CourseSyllabus.objects.filter(course=course).first()
    nodes = list(
        SyllabusNode.objects.filter(subject=subject, status='active', in_syllabus=True)
        .order_by('order', 'name')
    )
    by_id = {node.id: node for node in nodes}
    topics = []
    for node in nodes:
        if node.level != 'topic':
            continue
        parent = by_id.get(node.parent_id)
        topics.append({
            'key': node.key,
            'label': node.name,
            'description': node.description,
            'group': parent.name if parent else '',
            'course_topic_id': str(node.course_topic_id) if node.course_topic_id else None,
            'subtopics': [
                {'key': child.key, 'label': child.name, 'description': child.description}
                for child in nodes if child.parent_id == node.id and child.level == 'subtopic'
            ],
        })
    release = current_release()
    exam_label = _exam_label(record.exam_tree) if record and record.exam_tree else course.name
    audience = (record.audience if record and record.audience
                else f'Learners of the course "{course.name}"')
    return {
        'exam_label': exam_label,
        'audience': audience,
        'subject': subject.name,
        'review_threshold': release.review_confidence_threshold if release else DEFAULT_REVIEW_THRESHOLD,
        'taxonomy_version': release.version if release else '',
        'tree_version': compute_tree_version(subject),
        'topics': topics,
        'thinking_levels': _definitions(TagDefinition.KIND_THINKING),
        'special_formats': _definitions(TagDefinition.KIND_FORMAT),
        'skills': _definitions(TagDefinition.KIND_SKILL, packs_for_subject(subject)),
    }


def _plain(entry, pack=None):
    out = {'key': entry['key'], 'label': entry['label'], 'definition': entry['definition']}
    if pack is not None:
        out['pack'] = pack
    return out


def context_from_tree(tree, subject_key, tags):
    """The same context shape, straight from a validated tree + vocabulary (no DB)."""
    flat = [node for node in flatten_tree(tree) if node['subject'] == subject_key]
    subject = next((node for node in flat if node['level'] == 'subject'), None)
    if subject is None:
        raise TaxonomyError([f'{tree["key"]} has no subject {subject_key!r}'])
    groups = {node['key']: node['label'] for node in flat if node['level'] == 'sub_subject'}
    topics = []
    for node in flat:
        if node['level'] != 'topic' or not node['in_syllabus']:
            continue
        topics.append({
            'key': node['key'],
            'label': node['label'],
            'description': node['description'],
            'group': groups.get(node['parent_key'], ''),
            'course_topic_id': None,
            'subtopics': [
                {'key': child['key'], 'label': child['label'], 'description': child['description']}
                for child in flat if child['parent_key'] == node['key'] and child['in_syllabus']
            ],
        })
    names = [subject_key, subject['label'], *subject['aliases']]
    packs = [pack for pack in tags['packs'] if pack['active'] and pack_matches(pack['applies_to'], names)]
    rows = [(node['key'], node['label'], node['description'], node['level'], node['in_syllabus'])
            for node in sorted(flat, key=lambda n: n['key'])]
    return {
        'exam_label': tree['label'],
        'audience': tree['audience'],
        'subject': subject['label'],
        'review_threshold': tags['review_confidence_threshold'],
        'taxonomy_version': tags['version'],
        'tree_version': hashlib.sha256(json.dumps(rows, ensure_ascii=False).encode('utf-8')).hexdigest()[:16],
        'topics': topics,
        'thinking_levels': [_plain(e) for e in tags['thinking_levels'] if e['active']],
        'special_formats': [_plain(e) for e in tags['special_formats'] if e['active']],
        'skills': [_plain(e, '') for e in tags['universal_skills'] if e['active']]
                  + [_plain(e, pack['key']) for pack in packs for e in pack['skills'] if e['active']],
    }
```

```python
"""Map a course onto a shipped exam tree and instantiate its syllabus nodes.

    manage.py map_course_to_exam --course <id> --exam jee_main \
        --subject-map physics=<subject_id>,chemistry=<subject_id>,maths=<subject_id>
"""
import uuid

from django.core.management.base import BaseCommand, CommandError

from exams.models import Course, Subject
from intelligence.services.syllabus import instantiate_exam_tree
from intelligence.services.taxonomy import TaxonomyError


def _uuid(value, label):
    try:
        return uuid.UUID(str(value).strip())
    except ValueError as exc:
        raise CommandError(f'{label} {value!r} is not a valid id.') from exc


class Command(BaseCommand):
    help = 'Map a course onto an exam tree (taxonomy/exams/<exam>.yaml) and build its nodes.'

    def add_arguments(self, parser):
        parser.add_argument('--course', required=True)
        parser.add_argument('--exam', required=True, help='Exam tree key, e.g. jee_main.')
        parser.add_argument('--subject-map', required=True,
                            help='Comma-separated tree_subject=subject_id pairs.')
        parser.add_argument('--audience', default=None, help='Override the tree audience text.')

    def handle(self, *args, **options):
        course = Course.objects.filter(id=_uuid(options['course'], 'Course')).first()
        if course is None:
            raise CommandError('Course not found.')
        mapping = {}
        for part in options['subject_map'].split(','):
            if not part.strip():
                continue
            tree_key, _, subject_id = part.partition('=')
            subject = Subject.objects.filter(id=_uuid(subject_id, 'Subject'), course=course).first()
            if subject is None:
                raise CommandError(f'Subject {subject_id.strip()!r} is not part of this course.')
            mapping[tree_key.strip()] = subject
        if not mapping:
            raise CommandError('--subject-map is empty.')
        try:
            summary = instantiate_exam_tree(course, options['exam'], mapping, audience=options['audience'])
        except TaxonomyError as exc:
            raise CommandError('; '.join(exc.errors)) from exc

        self.stdout.write(
            f'{course.name} → {options["exam"]}: created {summary["created"]}, '
            f'updated {summary["updated"]}, archived {summary["archived"]}, '
            f'linked {summary["linked_topics"]} course topic(s).'
        )
        for line in summary['unmatched_topics']:
            self.stdout.write(f'  unmatched course topic — {line}')
        for line in summary['ambiguous_concepts']:
            self.stdout.write(f'  concept matches several subtopics, left alone — {line}')
        if summary['merged_concepts']:
            self.stdout.write(
                f'{summary["merged_concepts"]} existing concept(s) merged into tree subtopics; '
                'run `manage.py recompute_learner_state` next.'
            )
```

```python
class FakeCall:
    """Answers each stage from per-id tables; records prompts."""

    def __init__(self, locate=None, tag=None, fail=None):

        self.calls = []

        return self.store.get((stage, payload_id))

    def put(self, stage, payload_id, entry):
        self.store[(stage, payload_id)] = entry
```

```python
"""Tagger v2 (decisions D1–D6): exam-aware, tree-bound, two-stage, with confidence.

Pure core — no database access. ``tag_payloads`` takes a *context* (plain data:
see ``syllabus.tagging_context``), question *payloads* and a completion
callable ``call(system, user) -> str``, and returns one TagResult per payload.

Stage 1 (locate) runs only for payloads without a valid ``topic_hint``: it
picks the topic. Stage 2 (tag) runs per topic, with that topic's subtopics
(plus any "also" topics) in the prompt, and returns every other level.
"""
import json
import re
from dataclasses import dataclass, field

from coursegen.generation import GenerationError, extract_json

BATCH_SIZE = 12
QUESTION_CHARS = 2000
OPTION_CHARS = 300
MAX_OPTIONS = 8
MAX_ALSO_TOPICS = 2
MIN_SOLVE_S, MAX_SOLVE_S = 10, 1800
DISAGREEMENT_FACTOR = 0.8
DIFFICULTIES = ('easy', 'medium', 'hard')
REASON_CHARS = 200

LOCATE_MARKER = 'syllabus locator'
TAG_MARKER = 'assessment tagger'

FORMAT_HINTS = [
    ('assertion_reason', re.compile(r'assertion\s*\(?\s*a\s*\)?.*reason\s*\(?\s*r\s*\)?', re.I | re.S)),
    ('statement_pair', re.compile(r'statement[\s-]*(i|1)\b.*statement[\s-]*(ii|2)\b', re.I | re.S)),
    ('match_list', re.compile(r'(list|column)[\s-]*(i|1)\b.*(list|column)[\s-]*(ii|2)\b', re.I | re.S)),
]

LOCATE_SYSTEM = """
You are a syllabus locator for <<EXAM>>. Audience: <<AUDIENCE>>.
For each question choose the ONE topic it mainly belongs to, using a key from
TOPICS exactly as written. Optionally list up to 2 further topic keys it also
draws on. Give your confidence (0 to 1) that the main topic is right.

Return ONE JSON object, no markdown fences, no commentary:
{"items": [{"id": "<id exactly as given>", "topic_key": "...", "also_topic_keys": [], "confidence": 0.0}]}
Include every question id exactly once.
""".strip()

TAG_SYSTEM = """
You are an assessment tagger for <<EXAM>>. Audience: <<AUDIENCE>>.
Tag each question on every level below, using ONLY keys listed in the context.
- "primary_subtopic": the one SUBTOPIC key the question mainly tests.
- "secondary_subtopics": every other SUBTOPIC key it genuinely needs (no limit; may be empty).
- "thinking_level": exactly one THINKING LEVEL key, the highest the question demands.
- "skills": EVERY applicable SKILL (no limit): [{"key": "...", "role": "core" or "supporting", "reason": "<one line>"}].
  "core" means the question cannot be solved without that skill.
- "special_format": a SPECIAL FORMAT key if the question has that structure, else "".
  A "format_hint" on a question is a regex guess; confirm or ignore it.
- "difficulty": "easy", "medium" or "hard" for this audience.
- "est_solve_seconds": typical seconds a well-prepared student of this audience needs.
- "proposed_subtopic": normally "". If NO listed subtopic fits, a short name for the
  missing one, and leave primary_subtopic "".
- "confidence": 0 to 1, your confidence that primary_subtopic is right.

Return ONE JSON object, no markdown fences, no commentary:
{"items": [{"id": "...", "primary_subtopic": "...", "secondary_subtopics": [], "thinking_level": "...",
            "skills": [], "special_format": "", "difficulty": "...", "est_solve_seconds": 0,
            "proposed_subtopic": "", "confidence": 0.0}]}
Include every question id exactly once.
""".strip()


@dataclass
class TagResult:
    id: str
    topic_key: str = ''
    primary_subtopic: str = ''
    secondary_subtopics: list = field(default_factory=list)
    thinking_level: str = ''
    skills: list = field(default_factory=list)
    special_format: str = ''
    difficulty: str = ''
    est_solve_seconds: int | None = None
    proposed_subtopic: str = ''
    confidence: float = 0.0
    review_reasons: list = field(default_factory=list)
    needs_review: bool = True
    raw: dict = field(default_factory=dict)
    error: str = ''


class _NoCache:
    def get(self, stage, payload_id):
        return None

    def put(self, stage, payload_id, entry):
        return None


def cognitive_projection(thinking_level):
    """Three-value quiz ``cognitive_type`` from the five-value thinking level."""
    if thinking_level in ('recall', 'multi_concept'):
        return thinking_level
    return 'application' if thinking_level else ''


def format_hint(text):
    for key, pattern in FORMAT_HINTS:
        if pattern.search(text or ''):
            return key
    return ''


def _system(template, context):
    return template.replace('<<EXAM>>', context['exam_label']).replace('<<AUDIENCE>>', context['audience'])


def _question(payload, allowed_formats):
    out = {
        'id': str(payload['id']),
        'type': payload.get('type') or '',
        'question': (payload.get('question') or '')[:QUESTION_CHARS],
        'options': [str(option)[:OPTION_CHARS] for option in (payload.get('options') or [])[:MAX_OPTIONS]],
    }
    if payload.get('answer'):
        out['answer'] = str(payload['answer'])[:OPTION_CHARS]
    hint = format_hint(payload.get('question') or '')
    if hint and hint in allowed_formats:
        out['format_hint'] = hint
    return out


def _definition_lines(title, entries):
    return [f'{title}:'] + [f'- {e["key"]} | {e["label"]} — {e["definition"]}' for e in entries]


def _questions_block(context, payloads):
    allowed = {entry['key'] for entry in context['special_formats']}
    body = {'questions': [_question(payload, allowed) for payload in payloads]}
    return 'QUESTIONS:\n' + json.dumps(body, ensure_ascii=False)


def build_locate_prompt(context, payloads):
    lines = [f'SUBJECT: {context["subject"]}', 'TOPICS:']
    for topic in context['topics']:
        group = f' ({topic["group"]})' if topic.get('group') else ''
        desc = f' — {topic["description"]}' if topic.get('description') else ''
        lines.append(f'- {topic["key"]} | {topic["label"]}{group}{desc}')
    return _system(LOCATE_SYSTEM, context), '\n'.join(lines) + '\n\n' + _questions_block(context, payloads)


def build_tag_prompt(context, topic_keys, payloads):
    wanted = set(topic_keys)
    lines = [f'SUBJECT: {context["subject"]}', 'TOPICS AND THEIR SUBTOPICS:']
    for topic in context['topics']:
        if topic['key'] not in wanted:
            continue
        lines.append(f'* {topic["label"]} ({topic["key"]})')
        for sub in topic['subtopics']:
            desc = f' — {sub["description"]}' if sub.get('description') else ''
            lines.append(f'  - {sub["key"]} | {sub["label"]}{desc}')
    lines += _definition_lines('THINKING LEVELS', context['thinking_levels'])
    lines += _definition_lines('SKILLS', context['skills'])
    lines += _definition_lines('SPECIAL FORMATS', context['special_formats'])
    return _system(TAG_SYSTEM, context), '\n'.join(lines) + '\n\n' + _questions_block(context, payloads)


def _ask(call, system, user):
    """({id: entry}, error) for one completion."""
    try:
        content = call(system, user)
    except GenerationError as exc:
        return {}, f'call_failed: {exc}'[:200]
    try:
        parsed = extract_json(content)
    except GenerationError:
        return {}, 'unparseable_reply'
    items = parsed.get('items') if isinstance(parsed, dict) else None
    if not isinstance(items, list):
        return {}, 'unparseable_reply'
    return {str(entry.get('id')): entry for entry in items if isinstance(entry, dict)}, ''


def _confidence(value):
    try:
        number = float(value)
    except (TypeError, ValueError):
        return 0.0
    return min(1.0, max(0.0, number))


def _seconds(value):
    try:
        seconds = int(round(float(value)))
    except (TypeError, ValueError):
        return None
    return min(MAX_SOLVE_S, max(MIN_SOLVE_S, seconds))


def _batches(items):
    for start in range(0, len(items), BATCH_SIZE):
        yield items[start:start + BATCH_SIZE]


def _locate(entry, topic_keys):
    topic = entry.get('topic_key') if isinstance(entry.get('topic_key'), str) else ''
    if topic not in topic_keys:
        return None
    also = []
    for key in entry.get('also_topic_keys') or []:
        if isinstance(key, str) and key in topic_keys and key != topic and key not in also:
            also.append(key)
    return {'topic_key': topic, 'also': also[:MAX_ALSO_TOPICS], 'located': True}


def _apply_tag(result, entry, context, allowed, located):
    """Validate one stage-2 entry into ``result``. ``allowed``: subtopic → topic key."""
    reasons = set()
    primary = entry.get('primary_subtopic') if isinstance(entry.get('primary_subtopic'), str) else ''
    proposed = str(entry.get('proposed_subtopic') or '').strip()[:300]
    if primary and primary not in allowed:
        reasons.add('invalid_key')
        primary = ''
    if not primary and not proposed:
        reasons.add('invalid_key')
    result.primary_subtopic = primary
    secondaries = []
    for key in entry.get('secondary_subtopics') or []:
        if not isinstance(key, str) or key not in allowed:
            reasons.add('invalid_key')
        elif key != primary and key not in secondaries:
            secondaries.append(key)
    result.secondary_subtopics = secondaries if primary else []

    levels = {e['key'] for e in context['thinking_levels']}
    level = entry.get('thinking_level') or ''
    if level in levels:
        result.thinking_level = level
    elif level:
        reasons.add('invalid_key')

    skill_keys = {e['key'] for e in context['skills']}
    skills, seen = [], set()
    for raw in entry.get('skills') or []:
        if isinstance(raw, str):
            raw = {'key': raw}
        if not isinstance(raw, dict):
            continue
        key = raw.get('key')
        if key not in skill_keys:
            reasons.add('invalid_key')
            continue
        if key in seen:
            continue
        seen.add(key)
        skills.append({'key': key, 'role': 'core' if raw.get('role') == 'core' else 'supporting',
                       'reason': str(raw.get('reason') or '')[:REASON_CHARS]})
    result.skills = skills

    formats = {e['key'] for e in context['special_formats']}
    special = entry.get('special_format') or ''
    if special in formats:
        result.special_format = special
    elif special:
        reasons.add('invalid_key')

    result.difficulty = entry.get('difficulty') if entry.get('difficulty') in DIFFICULTIES else ''
    result.est_solve_seconds = _seconds(entry.get('est_solve_seconds'))
    result.proposed_subtopic = proposed
    if proposed:
        reasons.add('proposed_subtopic')

    confidence = _confidence(entry.get('confidence'))
    if primary:
        result.topic_key = allowed[primary]
        if located.get('located') and allowed[primary] != located['topic_key']:
            reasons.add('stage_disagreement')
            confidence *= DISAGREEMENT_FACTOR
    result.confidence = round(confidence, 4)
    if result.confidence < context['review_threshold']:
        reasons.add('low_confidence')
    result.review_reasons = sorted(reasons)
    result.needs_review = bool(reasons)


def tag_payloads(context, payloads, *, call, cache=None):
    """Tag ``payloads`` against ``context``. Never raises for model trouble."""
    cache = cache or _NoCache()
    results = {str(p['id']): TagResult(id=str(p['id'])) for p in payloads}
    topic_keys = {topic['key'] for topic in context['topics']}
    if not topic_keys:
        for result in results.values():
            result.error = 'no_tree'
        return [results[str(p['id'])] for p in payloads]

    # Stage 1 — locate the topic for payloads without a usable hint.
    located = {}
    pending = []
    for p in payloads:
        pid = str(p['id'])
        if p.get('topic_hint') in topic_keys:
            located[pid] = {'topic_key': p['topic_hint'], 'also': [], 'located': False}
            results[pid].topic_key = p['topic_hint']
            continue
        cached = cache.get('locate', pid)
        if cached is not None and _locate(cached, topic_keys):
            located[pid] = _locate(cached, topic_keys)
            results[pid].topic_key = located[pid]['topic_key']
            results[pid].raw['locate'] = cached
        else:
            pending.append(p)
    for batch in _batches(pending):
        system, user = build_locate_prompt(context, batch)
        entries, error = _ask(call, system, user)
        for p in batch:
            pid = str(p['id'])
            entry = entries.get(pid)
            if entry is None:
                results[pid].error = error or 'missing_from_reply'
                continue
            results[pid].raw['locate'] = entry
            found = _locate(entry, topic_keys)
            if found is None:
                results[pid].error = 'no_topic'
                continue
            cache.put('locate', pid, entry)
            located[pid] = found
            results[pid].topic_key = found['topic_key']

    # Stage 2 — tag, grouped by located topic.
    def allowed_for(keys):
        return {sub['key']: topic['key'] for topic in context['topics'] if topic['key'] in keys
                for sub in topic['subtopics']}

    groups = {}
    for p in payloads:
        pid = str(p['id'])
        if pid in located:
            groups.setdefault(located[pid]['topic_key'], []).append(p)
    for topic_key, group in groups.items():
        todo = []
        for p in group:
            pid = str(p['id'])
            cached = cache.get('tag', pid)
            if cached is not None:
                keys = [topic_key] + located[pid]['also']
                results[pid].raw['tag'] = cached
                _apply_tag(results[pid], cached, context, allowed_for(keys), located[pid])
            else:
                todo.append(p)
        for batch in _batches(todo):
            prompt_topics = [topic_key] + sorted(
                {key for p in batch for key in located[str(p['id'])]['also']} - {topic_key})
            system, user = build_tag_prompt(context, prompt_topics, batch)
            allowed = allowed_for(prompt_topics)
            entries, error = _ask(call, system, user)
            for p in batch:
                pid = str(p['id'])
                entry = entries.get(pid)
                if entry is None:
                    results[pid].error = error or 'missing_from_reply'
                    continue
                results[pid].raw['tag'] = entry
                cache.put('tag', pid, entry)
                _apply_tag(results[pid], entry, context, allowed, located[pid])
    return [results[str(p['id'])] for p in payloads]
```

```python
"""Completion callables for the tagging tools: ``call(system, user) -> text``.

Every call goes through ``coursegen.generation._call``, so it is metered into
AIUsageRecord (feature ``itemtag``) like any other AI call.
"""
from chatbot.models import AIUsageRecord, PlatformAIModel
from chatbot.providers import ResolvedProvider, estimate_cost_usd
from coursegen.generation import GenerationError, _Meter, _call

TAGGING_MAX_TOKENS = 8000


class MeteredCall:
    """A completion callable that also keeps tokens and per-call latency."""

    def __init__(self, resolved, tenant, *, feature=AIUsageRecord.FEATURE_ITEMTAG):
        self.resolved = resolved
        self.tenant = tenant
        self.feature = feature
        self.meter = _Meter()
        self.latencies_ms = []

    @property
    def model_ref(self):
        return f'{self.resolved.provider}:{self.resolved.model}'

    def cost_usd(self):
        return estimate_cost_usd(self.resolved.model, self.meter.usage,
                                 getattr(self.resolved, 'platform_model', None))

    def __call__(self, system, user):
        before = self.meter.elapsed_ms
        content = _call(self.resolved, system, user, self.meter, self.tenant, feature=self.feature)
        self.latencies_ms.append(self.meter.elapsed_ms - before)
        return content


def platform_call(model_name, tenant=None, *, max_tokens=TAGGING_MAX_TOKENS):
    """A call on a super-admin platform model (experiments and evaluation)."""
    platform_model = (
        PlatformAIModel.objects.select_related('provider')
        .filter(model_name=model_name, is_enabled=True, provider__is_enabled=True).first()
    )
    if platform_model is None:
        raise GenerationError(f'No enabled platform model named {model_name!r}.')
    return MeteredCall(ResolvedProvider.from_platform_model(platform_model, max_tokens=max_tokens), tenant)


def tenant_tagging_call(tenant):
    """A call on the tenant's tagging model (its own key, else the platform's)."""
    from intelligence.services.tagging import _resolve_tagging_model

    resolved = _resolve_tagging_model(tenant)
    # Stage-2 replies for 12 questions need more room than v1's 4000 tokens.
    resolved.max_tokens = max(resolved.max_tokens or 0, TAGGING_MAX_TOKENS)
    return MeteredCall(resolved, tenant)
```

```python
"""The tagging sweep: v2 for subjects with a syllabus tree, v1 for the rest.

DB shell around the pure core in ``tagging_v2``: it picks items, builds their
payloads and the subject context, caches each stage's reply per item content,
and writes ItemTagging / ItemSkillTag / ConceptLink rows.
"""
import logging
from collections import defaultdict

from django.db import transaction
from django.utils import timezone

from intelligence.models import AITaggingResult, ItemSkillTag, ItemTagging, SyllabusNode, TagDefinition
from intelligence.services import tagging as tagging_v1
from intelligence.services.itemtags import content_hash_for, replace_links
from intelligence.services.llm import tenant_tagging_call
from intelligence.services.syllabus import ensure_node_concept, tagging_context
from intelligence.services.tagging_v2 import cognitive_projection, tag_payloads
from intelligence.versions import TAGGER_V2_PROMPT_VERSION

logger = logging.getLogger(__name__)

LINK_VERSION_CHARS = 60  # ConceptLink.tagger_version max_length


class DbCache:
    """AITaggingResult-backed cache: one row per (content, stage, versions, model)."""

    def __init__(self, tenant, context, model_ref, hashes):
        self.tenant = tenant
        self.context = context
        self.model_ref = model_ref
        self.hashes = hashes

    def _key(self, stage, payload_id):
        return {
            'tenant': self.tenant,
            'content_hash': self.hashes[payload_id],
            'prompt_version': TAGGER_V2_PROMPT_VERSION,
            'taxonomy_version': self.context['taxonomy_version'],
            'tree_version': self.context['tree_version'],
            'stage': stage,
            'model_ref': self.model_ref,
        }

    def get(self, stage, payload_id):
        row = AITaggingResult.objects.filter(**self._key(stage, payload_id)).first()
        return row.result if row else None

    def put(self, stage, payload_id, entry):
        AITaggingResult.objects.get_or_create(**self._key(stage, payload_id), defaults={'result': entry})


def _arm(item):
    from quiz.models import MockTestItem

    return 'mock_item' if isinstance(item, MockTestItem) else 'question'


def item_payload(item):
    """Tagger payload for a bank Question or MockTestItem (answer as text)."""
    if _arm(item) == 'mock_item':
        options = [str(option.get('text') or '') for option in item.options or []]
        correct = [str(option.get('text') or '') for option in item.options or [] if option.get('is_correct')]
        fallback = str(item.numerical_answer) if item.numerical_answer is not None else ''
        item_type = item.item_type
    else:
        rows = list(item.options.order_by('order'))
        options = [row.option_text for row in rows]
        correct = [row.option_text for row in rows if row.is_correct]
        fallback = (str(item.numerical_answer) if item.numerical_answer is not None
                    else (item.correct_answer or ''))
        item_type = item.question_type
    return {
        'id': str(item.id),
        'type': item_type,
        'question': item.question_text or '',
        'options': options,
        'answer': ' | '.join(correct) or fallback,
    }


def _is_current(item, tagging, context):
    return (
        tagging is not None
        and item.tagging_status == 'tagged'
        and tagging.taxonomy_version == context['taxonomy_version']
        and tagging.tree_version == context['tree_version']
    )


def _replace_skill_tags(item, arm, skills):
    ItemSkillTag.objects.filter(**{arm: item}, source='llm_tagger').delete()
    manual = set(ItemSkillTag.objects.filter(**{arm: item}).values_list('skill__key', flat=True))
    definitions = {
        row.key: row for row in TagDefinition.objects.filter(
            kind=TagDefinition.KIND_SKILL, key__in=[skill['key'] for skill in skills])
    }
    ItemSkillTag.objects.bulk_create([
        ItemSkillTag(tenant=item.tenant, skill=definitions[skill['key']], role=skill['role'],
                     reason=skill['reason'], source='llm_tagger', **{arm: item})
        for skill in skills if skill['key'] in definitions and skill['key'] not in manual
    ])


@transaction.atomic
def write_result(item, result, context, nodes, tagger_version, *, subject, allow_difficulty):
    """Persist one TagResult. Returns the ItemTagging, or None when locked."""
    arm = _arm(item)
    tagging = ItemTagging.objects.filter(**{arm: item}).first()
    if tagging is not None and tagging.source == 'manual':
        return None
    was_untagged = not item.tagging_status

    primary = nodes.get(result.primary_subtopic)
    secondaries = [nodes[key] for key in result.secondary_subtopics if key in nodes] if primary else []
    concepts = [ensure_node_concept(node) for node in ([primary, *secondaries] if primary else [])]
    replace_links(item, concepts, source='llm_tagger', tagger_version=tagger_version[:LINK_VERSION_CHARS])

    if tagging is None:
        tagging = ItemTagging(tenant=item.tenant, **{arm: item})
    tagging.primary_node = primary
    tagging.thinking_level = result.thinking_level
    tagging.special_format = result.special_format
    tagging.difficulty_prior = result.difficulty
    tagging.est_solve_seconds = result.est_solve_seconds
    tagging.confidence = result.confidence
    tagging.review_status = ItemTagging.REVIEW_NEEDED if result.needs_review else ItemTagging.REVIEW_AUTO
    tagging.review_reasons = result.review_reasons
    tagging.proposed_subtopic = result.proposed_subtopic
    tagging.source = 'llm_tagger'
    tagging.tagger_version = tagger_version[:120]
    tagging.taxonomy_version = context['taxonomy_version']
    tagging.tree_version = context['tree_version']
    tagging.raw = result.raw
    tagging.save()
    tagging.secondary_nodes.set(secondaries)
    _replace_skill_tags(item, arm, result.skills)

    update_fields = ['content_hash', 'tagging_status', 'tagged_at', 'updated_at']
    item.content_hash = content_hash_for(item)
    item.tagging_status = 'tagged'
    item.tagged_at = timezone.now()
    projection = cognitive_projection(result.thinking_level)
    if projection:
        item.cognitive_type = projection
        update_fields.append('cognitive_type')
    if allow_difficulty and was_untagged and result.difficulty:
        item.difficulty = result.difficulty
        update_fields.append('difficulty')
    if item.topic_id is None and primary is not None and primary.parent and primary.parent.course_topic_id:
        item.topic_id = primary.parent.course_topic_id
        update_fields.append('topic')
    if arm == 'mock_item' and item.subject_id is None:
        item.subject = subject
        update_fields.append('subject')
    item.save(update_fields=list(dict.fromkeys(update_fields)))
    return tagging


def _tag_group(tenant, subject, context, items, call, *, arm):
    nodes = {
        node.key: node for node in
        SyllabusNode.objects.filter(subject=subject, status='active').select_related('parent', 'concept')
    }
    hints = {topic['course_topic_id']: topic['key'] for topic in context['topics'] if topic['course_topic_id']}
    by_id, hashes, payloads = {}, {}, []
    for item in items:
        payload = item_payload(item)
        payload['topic_hint'] = hints.get(str(item.topic_id), '') if item.topic_id else ''
        payloads.append(payload)
        by_id[payload['id']] = item
        hashes[payload['id']] = content_hash_for(item)
    results = tag_payloads(context, payloads, call=call,
                           cache=DbCache(tenant, context, call.model_ref, hashes))
    tagger_version = f'{TAGGER_V2_PROMPT_VERSION}:{call.model_ref}'
    written = 0
    for result in results:
        if result.error:
            logger.info('tagging v2: %s %s not tagged (%s)', arm, result.id, result.error)
            continue
        if write_result(by_id[result.id], result, context, nodes, tagger_version,
                        subject=subject, allow_difficulty=(arm == 'mock_item')):
            written += 1
    return written


def _mock_item_subject(item):
    if item.subject_id:
        return item.subject
    if item.topic_id:
        return item.topic.subject
    test = item.mock_test
    courses = list(test.courses.all()) or ([test.course] if test.course_id else [])
    subjects = [subject for course in courses for subject in course.subjects.all()]
    return subjects[0] if len(subjects) == 1 else None


def tag_v2_for_tenant(tenant, subject_ids, call, *, limit=200):
    """Tag up to ``limit`` not-current items of these (treed) subjects."""
    from quiz.models import MockTestItem, Question

    subject_ids = set(subject_ids)
    contexts, subjects = {}, {}
    picked = defaultdict(list)

    def context_for(subject):
        if subject.id not in contexts:
            contexts[subject.id] = tagging_context(subject)
        return contexts[subject.id]

    def take(arm, item, subject, tagging):
        if tagging is not None and tagging.source == 'manual':
            return False
        if _is_current(item, tagging, context_for(subject)):
            return False
        picked[(arm, subject.id)].append(item)
        subjects[subject.id] = subject
        return True

    taken = 0
    question_tags = {t.question_id: t for t in ItemTagging.objects.filter(tenant=tenant, question__isnull=False)}
    questions = (
        Question.objects.filter(tenant=tenant, subject_id__in=subject_ids).exclude(status='archived')
        .select_related('subject__course', 'topic').order_by('created_at')
    )
    for question in questions.iterator():
        if taken >= limit:
            break
        taken += take('question', question, question.subject, question_tags.get(question.id))

    item_tags = {t.mock_item_id: t for t in ItemTagging.objects.filter(tenant=tenant, mock_item__isnull=False)}
    items = (
        MockTestItem.objects.filter(tenant=tenant)
        .select_related('mock_test__course', 'subject__course', 'topic__subject__course')
        .order_by('created_at')
    )
    for item in items.iterator():
        if taken >= limit:
            break
        subject = _mock_item_subject(item)
        if subject is None or subject.id not in subject_ids:
            continue  # v1 handles it
        taken += take('mock_item', item, subject, item_tags.get(item.id))

    tagged = 0
    for (arm, subject_id), group in picked.items():
        subject = subjects[subject_id]
        tagged += _tag_group(tenant, subject, context_for(subject), group, call, arm=arm)
    return tagged


def run_sweep(tenant, *, limit=200, call=None):
    """Budget-gated pass: v2 where a syllabus tree exists, v1 everywhere else."""
    from coursegen.generation import _check_budget
```

  - from Task 4: `syllabus.ensure_node_concept` and `syllabus.norm`;
  - from Task 6: `llm.platform_call` and `llm.tenant_tagging_call`;
  - `normalize.concept_slug` and `coursegen.generation.extract_json` / `GenerationError`.
- Produces, in `intelligence.services.course_tree`:
  - `build_course_tree(course, *, call, packs=None, dry_run=False) -> summary`;
  - `summary` has `subjects`, `sub_subjects_created`, `topics_created`, `seeded_subtopics`, `proposed_subtopics`, `llm_calls`, `packs: {subject name: [pack keys]}` and `dry_run`;

  - the markers `GROUP_MARKER`, `SUBTOPIC_MARKER` and `PACK_MARKER`, which test fakes use to tell the calls apart.
- Behaviour (spec §4.2):
  - **Idempotent.** Existing nodes are kept. New course Topics go under the subject's first sub-subject. Subtopic proposals run only for topic nodes that have no subtopics yet.
  - **Node keys:**
    - sub-subject: `course.<subject code slug>.group.<slug>`, or `course.<code>.all` for the implicit group;
    - topic: `course.<code>.<topic code-or-name slug>`;
    - subtopic: `<topic key>.<slug>`.
    - A slug is `syllabus.norm(text)` with spaces turned into `_`, cut to 60 chars, or `x` when empty. A colliding key gets `_2`, `_3` and so on.
  - **Seeding:**
    - each active Concept linked to the topic (`Concept.topics`) that is not yet owned by a node becomes a subtopic node that owns it (source `course`);
    - a child Topic (`parent_topic` set) becomes a subtopic node (source `course`, `course_topic` = the child) with a new Concept, at most once;
    - a Concept linked to several topics is seeded under the first one only, by topic order.
  - **Proposals:**
    - a proposal is dropped when `concept_slug(name)` equals the slug of a seeded or earlier subtopic name in that topic;
    - an unowned active Concept in the same subject with the same slug is adopted, not duplicated;
    - other proposals get new nodes with source `llm_proposed`, status `active`, and a new Concept through `ensure_node_concept`.
  - **Packs:**
    - explicit `packs` are written for every subject;
    - otherwise one LLM call picks packs per subject from the active SkillPacks;
    - a failed call leaves `skill_packs` empty, so name matching applies.
  - **LLM failures:** any failed or unparseable call degrades gracefully. Grouping falls back to the implicit group, and the topic gets no proposals.
  - **`dry_run`:** the work runs inside a transaction that is rolled back. LLM calls still happen.

```python
"""Course-built syllabus trees for custom courses (spec §4.2, decision D5).

Topic level = the course's own Topics. Sub-subjects: one implicit group for
small subjects, else one LLM grouping call. Subtopics: existing Concepts
first (so mastery history carries over), then LLM proposals for what is
missing. Only question text — never student data — is sent to the model.
"""
import json

from django.db import transaction

from coursegen.generation import GenerationError, extract_json
from intelligence.services.normalize import concept_slug
from intelligence.services.syllabus import ensure_node_concept, norm

GROUP_THRESHOLD = 6
MAX_GROUPS = 8
MAX_PROPOSALS = 10
MAX_STEMS = 15
STEM_CHARS = 300
SLUG_CHARS = 60

GROUP_MARKER = 'syllabus organiser'
SUBTOPIC_MARKER = 'subtopic planner'
PACK_MARKER = 'skill-pack chooser'

GROUP_SYSTEM = f"""
You are a {GROUP_MARKER}. Group the TOPICS of one course subject into 2 to {MAX_GROUPS}
sub-subjects: coherent areas a teacher would name. Every topic id must appear in
exactly one group. Short group names (1-4 words).
Return ONE JSON object, no markdown fences: {{"groups": [{{"name": "...", "topic_ids": ["..."]}}]}}
""".strip()

SUBTOPIC_SYSTEM = f"""
You are a {SUBTOPIC_MARKER}. Break one course topic into subtopics: the distinct,
separately testable ideas a question could target. EXISTING subtopics are kept;
add only the missing ones (0 to {MAX_PROPOSALS}). Short names (2-6 words), no numbering.
Return ONE JSON object, no markdown fences: {{"subtopics": [{{"name": "...", "description": "<one line>"}}]}}
""".strip()

PACK_SYSTEM = f"""
You are a {PACK_MARKER}. For each subject, pick the skill packs whose skills its
questions exercise. Use only the pack keys listed; a subject may get none.
Return ONE JSON object, no markdown fences: {{"subjects": [{{"id": "...", "packs": ["..."]}}]}}
""".strip()


class _Rollback(Exception):
    pass


def _slug(text):
    return (norm(text).replace(' ', '_')[:SLUG_CHARS].strip('_')) or 'x'


def _ask_json(call, system, payload, summary):
    summary['llm_calls'] += 1
    try:
        return extract_json(call(system, json.dumps(payload, ensure_ascii=False)))
    except GenerationError:
        return None


def _unique_key(base, used):
    key, suffix = base, 2
    while key in used:
        key, suffix = f'{base}_{suffix}', suffix + 1
    used.add(key)
    return key


def _group_topics(subject, topics, call, summary):
    """[(group name, [topics])] — implicit group, LLM grouping, or fallback."""
    if len(topics) <= GROUP_THRESHOLD:
        return [(None, topics)]
    payload = {'subject': subject.name,
               'topics': [{'id': str(topic.id), 'name': topic.name} for topic in topics]}
    reply = _ask_json(call, GROUP_SYSTEM, payload, summary)
    by_id = {str(topic.id): topic for topic in topics}
    groups, placed = [], set()
    for raw in (reply or {}).get('groups') or []:
        if not isinstance(raw, dict) or len(groups) >= MAX_GROUPS:
            continue
        name = str(raw.get('name') or '').strip()[:300]
        members = [by_id[tid] for tid in raw.get('topic_ids') or []
                   if isinstance(tid, str) and tid in by_id and tid not in placed]
        if not name or not members:
            continue
        placed.update(str(topic.id) for topic in members)
        groups.append((name, members))
    if not groups:
        return [(None, topics)]
    rest = [topic for topic in topics if str(topic.id) not in placed]
    if rest:
        groups.append(('Other', rest))
    return groups


def _subject_code(subject):
    return _slug(subject.code or subject.name)


def _ensure_groups(subject, topics, call, summary, used):
    """Create sub-subject + topic nodes for topics not yet in the tree."""
    from intelligence.models import SyllabusNode

    existing = {node.course_topic_id: node for node in
                SyllabusNode.objects.filter(subject=subject, level='topic').exclude(status='archived')}
    new_topics = [topic for topic in topics if topic.id not in existing]
    if not new_topics:
        return existing
    code = _subject_code(subject)
    first_group = (SyllabusNode.objects.filter(subject=subject, level='sub_subject')
                   .exclude(status='archived').order_by('order').first())
    if first_group is not None:
        plan = [(first_group, new_topics)]
    else:
        plan = []
        for order, (name, members) in enumerate(_group_topics(subject, new_topics, call, summary)):
            key = (f'course.{code}.all' if name is None
                   else _unique_key(f'course.{code}.group.{_slug(name)}', used))
            group = SyllabusNode.objects.create(
                tenant=subject.tenant, subject=subject, level='sub_subject', key=key,
                name=(subject.name if name is None else name)[:300], source='course', order=order,
            )
            summary['sub_subjects_created'] += 1
            plan.append((group, members))
    for group, members in plan:
        for topic in members:
            key = _unique_key(f'course.{code}.{_slug(topic.code or topic.name)}', used)
            existing[topic.id] = SyllabusNode.objects.create(
                tenant=subject.tenant, subject=subject, parent=group, level='topic', key=key,
                name=topic.name[:300], description=(topic.description or '')[:2000],
                course_topic=topic, source='course', order=topic.order,
            )
            summary['topics_created'] += 1
    return existing


def _seed_subtopics(subject, topic_nodes, topics, summary, used):
    from intelligence.models import Concept, SyllabusNode

    owned = set(SyllabusNode.objects.filter(subject=subject, concept__isnull=False)
                .values_list('concept_id', flat=True))
    for topic in topics:  # topic order decides where a shared concept lands
        node = topic_nodes[topic.id]
        for concept in Concept.objects.filter(subject=subject, status='active', topics=topic).order_by('name'):
            if concept.id in owned:
                continue
            SyllabusNode.objects.create(
                tenant=subject.tenant, subject=subject, parent=node, level='subtopic',
                key=_unique_key(f'{node.key}.{_slug(concept.name)}', used), name=concept.name[:300],
                source='course', concept=concept,
            )
            owned.add(concept.id)
            summary['seeded_subtopics'] += 1
        for child in topic.subtopics.all().order_by('order', 'name'):
            if SyllabusNode.objects.filter(subject=subject, level='subtopic', course_topic=child).exists():
                continue
            child_node = SyllabusNode.objects.create(
                tenant=subject.tenant, subject=subject, parent=node, level='subtopic',
                key=_unique_key(f'{node.key}.{_slug(child.name)}', used), name=child.name[:300],
                description=(child.description or '')[:2000], source='course', course_topic=child,
            )
            ensure_node_concept(child_node)
            summary['seeded_subtopics'] += 1


def _propose_subtopics(subject, node, topic, call, summary, used, before):
    """LLM proposals for one topic — only on the run that first plans it."""
    from intelligence.models import Concept, SyllabusNode
    from quiz.models import Question

    existing = list(SyllabusNode.objects.filter(parent=node, level='subtopic').exclude(status='archived'))
    if any(child.id in before for child in existing):
        return  # this topic was planned in an earlier run
    seen = {concept_slug(child.name) for child in existing}
    stems = list(Question.objects.filter(topic=topic).exclude(status='archived')
                 .order_by('created_at').values_list('question_text', flat=True)[:MAX_STEMS])
    payload = {
        'subject': subject.name, 'topic': topic.name, 'objectives': topic.objectives or [],
        'existing_subtopics': [child.name for child in existing],
        'sample_questions': [(stem or '')[:STEM_CHARS] for stem in stems],
    }
    reply = _ask_json(call, SUBTOPIC_SYSTEM, payload, summary)
    for raw in ((reply or {}).get('subtopics') or [])[:MAX_PROPOSALS]:
        if not isinstance(raw, dict):
            continue
        name = ' '.join(str(raw.get('name') or '').split())[:300]
        slug = concept_slug(name)
        if not slug or slug in seen:
            continue
        seen.add(slug)
        adopt = (Concept.objects.filter(subject=subject, status='active', slug=slug)
                 .exclude(syllabus_node__isnull=False).first())
        child = SyllabusNode.objects.create(
            tenant=subject.tenant, subject=subject, parent=node, level='subtopic',
            key=_unique_key(f'{node.key}.{_slug(name)}', used), name=name,
            description=str(raw.get('description') or '').strip()[:2000],
            source='llm_proposed', concept=adopt,
        )
        if adopt is None:
            ensure_node_concept(child)
        else:
            adopt.topics.add(topic)
        summary['proposed_subtopics'] += 1


def _choose_packs(subjects, call, summary):
    from intelligence.models import SkillPack

    packs = {pack.key: pack.label for pack in SkillPack.objects.filter(active=True)}
    payload = {'packs': [{'key': key, 'label': label} for key, label in sorted(packs.items())],
               'subjects': [{'id': str(subject.id), 'name': subject.name} for subject in subjects]}
    reply = _ask_json(call, PACK_SYSTEM, payload, summary)
    chosen = {}
    for raw in (reply or {}).get('subjects') or []:
        if isinstance(raw, dict) and isinstance(raw.get('packs'), list):
            chosen[str(raw.get('id'))] = [key for key in raw['packs'] if key in packs]
    return chosen


def _build(course, call, packs, summary):
    from exams.models import Topic
    from intelligence.models import CourseSyllabus, SkillPack, SyllabusNode

    record, _ = CourseSyllabus.objects.get_or_create(
        course=course, defaults={
            'tenant': course.tenant,
            'audience': f'Learners of "{course.name}" ({course.get_course_type_display()})'[:200],
        })
    subjects = list(course.subjects.all().order_by('order', 'name'))
    for subject in subjects:
        summary['subjects'] += 1
        used = set(SyllabusNode.objects.filter(subject=subject).values_list('key', flat=True))
        before = set(SyllabusNode.objects.filter(subject=subject, level='subtopic').values_list('id', flat=True))
        topics = list(Topic.objects.filter(subject=subject, parent_topic__isnull=True).order_by('order', 'name'))
        topic_nodes = _ensure_groups(subject, topics, call, summary, used)
        topics = [topic for topic in topics if topic.id in topic_nodes]
        _seed_subtopics(subject, topic_nodes, topics, summary, used)
        for topic in topics:
            _propose_subtopics(subject, topic_nodes[topic.id], topic, call, summary, used, before)

    if packs is not None:
        active = set(SkillPack.objects.filter(active=True).values_list('key', flat=True))
        chosen = {str(subject.id): [key for key in packs if key in active] for subject in subjects}
    else:
        chosen = _choose_packs(subjects, call, summary) if subjects else {}
    record.skill_packs = {sid: keys for sid, keys in chosen.items() if keys}
    record.save()
    names = {str(subject.id): subject.name for subject in subjects}
    summary['packs'] = {names[sid]: keys for sid, keys in record.skill_packs.items() if sid in names}


def build_course_tree(course, *, call, packs=None, dry_run=False):
    """Build or extend the syllabus tree of every subject in ``course``."""
    summary = {'subjects': 0, 'sub_subjects_created': 0, 'topics_created': 0, 'seeded_subtopics': 0,
               'proposed_subtopics': 0, 'llm_calls': 0, 'packs': {}, 'dry_run': dry_run}
    try:
        with transaction.atomic():
            _build(course, call, packs, summary)
            if dry_run:
                raise _Rollback
    except _Rollback:
        pass
    return summary
```

A topic is planned (sent for proposals) once: on the first run that sees it. Its seeded subtopics are created in the same run, so they do not block proposals. A later run skips any topic whose subtopics already existed before that run started (`before`).

```python
"""Scoring the v2 tagger against gold files (spec §6). Pure; no database.

Every metric is computed only over gold rows that carry that field; an item
missing from the results (call/parse failure) counts as wrong.
"""
import math

DIFFICULTY_RANK = {'easy': 0, 'medium': 1, 'hard': 2}
TARGET_SUBTOPIC_ACCURACY = 0.8

ROWS = [
    ('n', 'Questions'),
    ('topic_accuracy', 'Topic accuracy (blind)'),
    ('subtopic_exact', 'Subtopic exact'),
    ('subtopic_hit', 'Subtopic hit'),
    ('thinking_accuracy', 'Thinking level'),
    ('skills.f1', 'Skills micro-F1'),
    ('core_skills.f1', 'Core skills F1'),
    ('difficulty_accuracy', 'Difficulty exact'),
    ('difficulty_within_one', 'Difficulty ±1'),
    ('error_rate', 'Errors (call/parse)'),
    ('invalid_key_rate', 'Invalid-key rate'),
    ('needs_review_rate', 'Needs review'),
    ('suggested_threshold', 'Suggested review threshold'),
    ('tokens_per_question', 'Tokens / question'),
    ('latency_p50_ms', 'Latency p50 (ms per call)'),
    ('latency_p95_ms', 'Latency p95 (ms per call)'),
    ('cost_per_1000_usd', 'Cost / 1,000 questions (USD)'),
]


def _ratio(num, den):
    return round(num / den, 4) if den else None


def _prf(tp, fp, fn):
    return {
        'precision': _ratio(tp, tp + fp),
        'recall': _ratio(tp, tp + fn),
        'f1': _ratio(2 * tp, 2 * tp + fp + fn),
    }


def _gold(row, field):
    return (row.get('gold') or {}).get(field)


def suggest_threshold(buckets, target=TARGET_SUBTOPIC_ACCURACY):
    """Lowest bucket floor b such that items with confidence ≥ b reach ``target``."""
    for floor in range(10):
        n = sum(v['n'] for k, v in buckets.items() if k >= floor)
        exact = sum(v['exact'] for k, v in buckets.items() if k >= floor)
        if n and exact / n >= target:
            return floor / 10
    return None


def score(gold_rows, results, *, mode):
    by_id = {result.id: result for result in results}
    pairs = [(row, by_id.get(str(row['id']))) for row in gold_rows]
    n = len(pairs)
    metrics = {'n': n, 'mode': mode}
    metrics['error_rate'] = _ratio(sum(1 for _, r in pairs if r is None or r.error), n)
    metrics['invalid_key_rate'] = _ratio(
        sum(1 for _, r in pairs if r is not None and 'invalid_key' in r.review_reasons), n)
    metrics['needs_review_rate'] = _ratio(sum(1 for _, r in pairs if r is None or r.needs_review), n)

    if mode == 'blind':
        rows = [(g, r) for g, r in pairs if _gold(g, 'topic')]
        metrics['topic_accuracy'] = _ratio(
            sum(1 for g, r in rows if r is not None and r.topic_key == _gold(g, 'topic')), len(rows))

    sub_rows = [(g, r) for g, r in pairs if _gold(g, 'subtopic')]
    metrics['subtopic_exact'] = _ratio(
        sum(1 for g, r in sub_rows if r is not None and r.primary_subtopic == _gold(g, 'subtopic')),
        len(sub_rows))
    metrics['subtopic_hit'] = _ratio(
        sum(1 for g, r in sub_rows
            if r is not None and _gold(g, 'subtopic') in [r.primary_subtopic, *r.secondary_subtopics]),
        len(sub_rows))

    level_rows = [(g, r) for g, r in pairs if _gold(g, 'thinking_level')]
    confusion = {}
    for g, r in level_rows:
        predicted = (r.thinking_level if r is not None else '') or '(none)'
        row = confusion.setdefault(_gold(g, 'thinking_level'), {})
        row[predicted] = row.get(predicted, 0) + 1
    metrics['thinking_accuracy'] = _ratio(
        sum(1 for g, r in level_rows if r is not None and r.thinking_level == _gold(g, 'thinking_level')),
        len(level_rows))
    metrics['thinking_confusion'] = confusion

    def skill_score(field, core_only):
        rows = [(g, r) for g, r in pairs if _gold(g, field) is not None]
        if not rows:
            return None
        tp = fp = fn = 0
        for g, r in rows:
            predicted = {s['key'] for s in (r.skills if r is not None else [])
                         if not core_only or s['role'] == 'core'}
            wanted = set(_gold(g, field))
            tp += len(predicted & wanted)
            fp += len(predicted - wanted)
            fn += len(wanted - predicted)
        return _prf(tp, fp, fn)

    metrics['skills'] = skill_score('skills', core_only=False)
    metrics['core_skills'] = skill_score('core_skills', core_only=True)

    diff_rows = [(g, r) for g, r in pairs if _gold(g, 'difficulty') in DIFFICULTY_RANK]
    metrics['difficulty_accuracy'] = _ratio(
        sum(1 for g, r in diff_rows if r is not None and r.difficulty == _gold(g, 'difficulty')),
        len(diff_rows))
    metrics['difficulty_within_one'] = _ratio(
        sum(1 for g, r in diff_rows if r is not None and r.difficulty in DIFFICULTY_RANK
            and abs(DIFFICULTY_RANK[r.difficulty] - DIFFICULTY_RANK[_gold(g, 'difficulty')]) <= 1),
        len(diff_rows))

    fmt_rows = [(g, r) for g, r in pairs if 'special_format' in (g.get('gold') or {})]
    formats = ({_gold(g, 'special_format') for g, _ in fmt_rows}
               | {r.special_format for _, r in fmt_rows if r is not None}) - {'', None}
    special = {}
    for key in sorted(formats):
        tp = sum(1 for g, r in fmt_rows if _gold(g, 'special_format') == key and r is not None
                 and r.special_format == key)
        fp = sum(1 for g, r in fmt_rows if r is not None and r.special_format == key
                 and _gold(g, 'special_format') != key)
        fn = sum(1 for g, r in fmt_rows if _gold(g, 'special_format') == key
                 and (r is None or r.special_format != key))
        special[key] = _prf(tp, fp, fn)
    metrics['special_formats'] = special

    buckets = {}
    for g, r in sub_rows:
        if r is None or r.error:
            continue
        bucket = buckets.setdefault(min(9, int(r.confidence * 10)), {'n': 0, 'exact': 0})
        bucket['n'] += 1
        bucket['exact'] += int(r.primary_subtopic == _gold(g, 'subtopic'))
    metrics['calibration'] = [
        {'from': floor / 10, 'n': v['n'], 'subtopic_exact': _ratio(v['exact'], v['n'])}
        for floor, v in sorted(buckets.items())
    ]
    metrics['suggested_threshold'] = suggest_threshold(buckets)
    return metrics


def percentile(values, pct):
    if not values:
        return None
    ordered = sorted(values)
    index = min(len(ordered) - 1, max(0, math.ceil(pct / 100 * len(ordered)) - 1))
    return ordered[index]


def _lookup(entry, path):
    value = entry
    for part in path.split('.'):
        if not isinstance(value, dict):
            return None
        value = value.get(part)
    return value


def _cell(value):
    if value is None:
        return '—'
    if isinstance(value, float) and not isinstance(value, bool):
        return f'{value:.3f}' if value <= 1 else f'{value:.1f}'
    return str(value)


def render_markdown(report):
    names = list(report['models'])
    lines = [
        f'Gold: {report["gold"]} · mode: {report["mode"]}',
        '',
        '| Metric | ' + ' | '.join(names) + ' |',
        '|---|' + '---|' * len(names),
    ]
    for path, label in ROWS:
        if path == 'topic_accuracy' and report['mode'] != 'blind':
            continue
        cells = [_cell(_lookup(report['models'][name], path)) for name in names]
        lines.append(f'| {label} | ' + ' | '.join(cells) + ' |')
    for name in names:
        calibration = report['models'][name].get('calibration') or []
        if calibration:
            buckets = ', '.join(f'≥{c["from"]:.1f}: {_cell(c["subtopic_exact"])} (n={c["n"]})' for c in calibration)
            lines += ['', f'Calibration — {name}: {buckets}']
    return '\n'.join(lines)
```

```python
Track B rows carry only the gold topic (the course Topic the question sits

def _checked_out_path(raw):
    path = Path(raw).resolve()
    if 'data_dumps' not in path.parts:
        raise CommandError('Gold files hold licensed or production text: --out must be under data_dumps/.')
    path.parent.mkdir(parents=True, exist_ok=True)
    return path


class Command(BaseCommand):
    help = 'Write a gold JSONL file for evaluate_tagger (from eval_jee, or from a course).'

    def add_arguments(self, parser):
        source = parser.add_mutually_exclusive_group(required=True)
        source.add_argument('--eval-jee', dest='eval_jee', help='Path to the local eval_jee.jsonl.')
        source.add_argument('--course', help='Course id (Track B).')
        parser.add_argument('--out', required=True)
        parser.add_argument('--n', type=int, default=300)
        parser.add_argument('--seed', type=int, default=7)
        parser.add_argument('--exam', default='jee_main')

    def handle(self, *args, **options):
        out = _checked_out_path(options['out'])
        rows = self._from_eval_jee(options) if options['eval_jee'] else self._from_course(options)
        with open(out, 'w', encoding='utf-8') as handle:
            for row in rows:
                handle.write(json.dumps(row, ensure_ascii=False) + '\n')
        self.stdout.write(self.style.SUCCESS(f'Wrote {len(rows)} gold row(s) to {out}'))

    def _from_eval_jee(self, options):
        try:
            tree = load_exam_tree(options['exam'])
        except TaxonomyError as exc:
            raise CommandError('; '.join(exc.errors)) from exc
        index = tree_key_index(tree)
        excluded = out_of_syllabus_chapters(tree)
        pool = [
            row for row in read_rows(options['eval_jee'])
            if is_usable(row, excluded) and (row['subject'], row['chapter'], row['topic']) in index
        ]
        gold = []
        for row in stratified_sample(pool, options['n'], options['seed']):
            topic_key = index[(row['subject'], row['chapter'])]
            gold.append({
                **row_to_payload(row),
                'subject': row['subject'],
                'topic_hint': topic_key,
                'gold': {'topic': topic_key, 'subtopic': index[(row['subject'], row['chapter'], row['topic'])]},
                'source': {'paper_id': row.get('paper_id', '')},
            })
        return gold

    def _from_course(self, options):
        from quiz.models import Question

        try:
            course = Course.objects.filter(id=uuid.UUID(options['course'])).first()
        except ValueError as exc:
            raise CommandError('--course is not a valid id.') from exc
        if course is None:
            raise CommandError('Course not found.')
        topic_keys = dict(
            SyllabusNode.objects.filter(subject__course=course, level='topic', status='active',
                                        course_topic__isnull=False)
            .values_list('course_topic_id', 'key')
        )
        if not topic_keys:
            raise CommandError('This course has no syllabus tree yet — run build_course_tree first.')
        questions = {
            str(q.id): q for q in Question.objects.filter(subject__course=course, topic_id__in=list(topic_keys))
            .exclude(status='archived').select_related('subject', 'topic')
        }
        pool = [{'question_id': qid, 'subject': str(q.subject_id), 'chapter': str(q.topic_id)}
                for qid, q in questions.items()]
        gold = []
        for picked in stratified_sample(pool, options['n'], options['seed']):
            question = questions[picked['question_id']]
            topic_key = topic_keys[question.topic_id]
            gold.append({
                **item_payload(question),
                'subject': str(question.subject_id),
                'topic_hint': topic_key,
                'gold': {'topic': topic_key},
                'source': {'course': str(course.id), 'topic': question.topic.name},
            })
        return gold
```

```python
"""Score tagging models on a gold file (spec §6.2). No DB writes except usage metering.

    manage.py evaluate_tagger --gold ../data_dumps/jee_eval/gold_location.jsonl \
        --models gpt-6-luna --mode anchored --exam jee_main --out ../data_dumps/jee_eval/report.json

import json
import uuid
from itertools import groupby
from pathlib import Path

from django.core.management.base import BaseCommand, CommandError

from coursegen.generation import GenerationError
from exams.models import Course, Subject
from intelligence.services.eval_jee import read_rows
from intelligence.services.llm import platform_call

from intelligence.services.tag_eval import percentile, render_markdown, score
from intelligence.services.tagging_v2 import tag_payloads
from intelligence.services.taxonomy import TaxonomyError, load_exam_tree, load_tags

PAYLOAD_FIELDS = ('id', 'type', 'question', 'options', 'answer')


class Command(BaseCommand):
    help = 'Evaluate tagging models against a gold JSONL file.'

    def add_arguments(self, parser):
        parser.add_argument('--gold', required=True)
        parser.add_argument('--models', required=True, help='Comma-separated platform model names.')
        parser.add_argument('--mode', choices=['anchored', 'blind'], default='anchored')
        tree = parser.add_mutually_exclusive_group(required=True)
        tree.add_argument('--exam', help='Exam tree key (contexts from YAML).')
        tree.add_argument('--course', help='Course id (contexts from its syllabus tree).')
        parser.add_argument('--limit', type=int, default=None)
        parser.add_argument('--out', default=None, help='Write the JSON report here (under data_dumps/).')

    def handle(self, *args, **options):
        rows = read_rows(options['gold'])[:options['limit'] or None]
        if not rows:
            raise CommandError('The gold file is empty.')
        contexts, tenant = self._contexts(options, {row['subject'] for row in rows})
        rows.sort(key=lambda row: str(row['subject']))
        report = {'gold': options['gold'], 'mode': options['mode'], 'models': {}}
        items = {}
        for model in [m.strip() for m in options['models'].split(',') if m.strip()]:
            try:
                call = platform_call(model, tenant)
            except GenerationError as exc:
                raise CommandError(str(exc)) from exc
            results = []
            for subject, group in groupby(rows, key=lambda row: str(row['subject'])):
                payloads = [
                    {**{field: row.get(field) for field in PAYLOAD_FIELDS},
                     'topic_hint': row.get('topic_hint', '') if options['mode'] == 'anchored' else ''}
                    for row in group
                ]
                results.extend(tag_payloads(contexts[subject], payloads, call=call))
            metrics = score(rows, results, mode=options['mode'])
            usage = call.meter.usage
            report['models'][model] = {
                **metrics,
                'tokens_per_question': round(usage.total_tokens / len(rows), 1),
                'latency_p50_ms': percentile(call.latencies_ms, 50),
                'latency_p95_ms': percentile(call.latencies_ms, 95),
                'cost_per_1000_usd': round(call.cost_usd() / len(rows) * 1000, 4),
                'calls': len(call.latencies_ms),
            }
            items[model] = [
                {'id': r.id, 'topic': r.topic_key, 'primary': r.primary_subtopic,
                 'secondary': r.secondary_subtopics, 'thinking_level': r.thinking_level,
                 'skills': r.skills, 'special_format': r.special_format, 'difficulty': r.difficulty,
                 'est_solve_seconds': r.est_solve_seconds, 'confidence': r.confidence,
                 'review_reasons': r.review_reasons, 'proposed_subtopic': r.proposed_subtopic,
                 'error': r.error}
                for r in results
            ]
        self.stdout.write(render_markdown(report))
        if options['out']:
            out = Path(options['out']).resolve()
            if 'data_dumps' not in out.parts:
                raise CommandError('--out must be under data_dumps/.')
            out.write_text(json.dumps({'report': report, 'items': items}, ensure_ascii=False, indent=1),
                           encoding='utf-8')
            self.stdout.write(f'Report written to {out}')

    def _contexts(self, options, subjects):
        if options['exam']:
            try:
                tags, _ = load_tags()
                tree = load_exam_tree(options['exam'])
                return {key: context_from_tree(tree, key, tags) for key in subjects}, None
            except TaxonomyError as exc:
                raise CommandError('; '.join(exc.errors)) from exc
        try:
            course = Course.objects.filter(id=uuid.UUID(options['course'])).first()
        except ValueError as exc:
            raise CommandError('--course is not a valid id.') from exc
        if course is None:
            raise CommandError('Course not found.')
        by_id = {str(s.id): s for s in Subject.objects.filter(course=course, id__in=list(subjects))}
        missing = sorted(set(subjects) - set(by_id))
        if missing:
            raise CommandError(f'Gold subjects not in this course: {", ".join(missing)}')
        return {sid: tagging_context(subject) for sid, subject in by_id.items()}, course.tenant
```

```python
"""Dev only: build a local JEE Lab tenant from the eval_jee dataset (D10, Track A).

    manage.py import_eval_jee --file ../data_dumps/jee_eval/eval_jee.jsonl --tenant lab-jee --limit 600

Refuses unless DEBUG is on, the tenant subdomain starts with "lab-" and the
database is local: the dataset has no licence and must never reach a shared
database. The dataset's subtopic labels are never stored (they live only in
gold files), so the tagger cannot see them.
"""
from decimal import Decimal, InvalidOperation

from django.conf import settings
from django.core.management.base import BaseCommand, CommandError
from django.db import connection, transaction

from core.models import Tenant
from exams.models import Course, Subject, Topic
from intelligence.services.eval_jee import (
    TYPE_MAP, correct_ids, is_usable, out_of_syllabus_chapters, parse_options, read_rows,
    strip_html, stratified_sample, tree_key_index,
)
from intelligence.services.syllabus import instantiate_exam_tree
from intelligence.services.taxonomy import TaxonomyError, flatten_tree, load_exam_tree
from quiz.models import Question, QuestionOption

LOCAL_HOSTS = {'', 'localhost', '127.0.0.1', '::1'}
TAG_PREFIX = 'eval_jee:'


def database_is_local():
    database = connection.settings_dict
    return 'sqlite' in database.get('ENGINE', '') or (database.get('HOST') or '') in LOCAL_HOSTS


class Command(BaseCommand):
    help = 'Dev only: create a local JEE Lab tenant from the eval_jee dataset.'

    def add_arguments(self, parser):
        parser.add_argument('--file', required=True, help='Path to the local eval_jee.jsonl.')
        parser.add_argument('--tenant', required=True, help='Lab tenant subdomain; must start with "lab-".')
        parser.add_argument('--limit', type=int, default=None, help='Stratified sample of the pool.')
        parser.add_argument('--seed', type=int, default=7)
        parser.add_argument('--exam', default='jee_main')

    def handle(self, *args, **options):
        subdomain = options['tenant']
        if not settings.DEBUG:
            raise CommandError('import_eval_jee is dev-only: DEBUG must be on.')
        if not subdomain.startswith('lab-'):
            raise CommandError('The lab tenant subdomain must start with "lab-".')
        if not database_is_local():
            raise CommandError('Refusing: the default database is not local.')
        try:
            tree = load_exam_tree(options['exam'])
        except TaxonomyError as exc:
            raise CommandError('; '.join(exc.errors)) from exc

        index = tree_key_index(tree)
        excluded = out_of_syllabus_chapters(tree)
        pool = [row for row in read_rows(options['file'])
                if is_usable(row, excluded) and (row['subject'], row['chapter']) in index]
        if options['limit']:
            pool = stratified_sample(pool, options['limit'], options['seed'])

        with transaction.atomic():
            tenant, _ = Tenant.objects.get_or_create(
                subdomain=subdomain, defaults={'name': 'JEE Lab', 'is_active': True})
            course, _ = Course.objects.get_or_create(
                code=f'{subdomain}-jee-main',
                defaults={'tenant': tenant, 'name': f'{tree["label"]} (Lab)', 'course_type': 'competitive'})
            if course.tenant_id != tenant.id:
                raise CommandError(f'Course {course.code} belongs to another tenant.')
            flat = flatten_tree(tree)
            subjects, topics = {}, {}
            for node in flat:
                if node['level'] == 'subject':
                    subjects[node['local_key']] = Subject.objects.get_or_create(
                        tenant=tenant, course=course, code=node['local_key'],
                        defaults={'name': node['label'], 'order': node['order']})[0]
            for node in flat:
                if node['level'] == 'topic' and node['in_syllabus']:
                    topics[node['key']] = Topic.objects.get_or_create(
                        tenant=tenant, subject=subjects[node['subject']], code=node['local_key'],
                        defaults={'name': node['label'], 'order': node['order']})[0]
            tree_summary = instantiate_exam_tree(course, tree['key'], subjects)

            existing = {
                tag for tags in Question.objects.filter(tenant=tenant).values_list('tags', flat=True)
                for tag in (tags or []) if isinstance(tag, str) and tag.startswith(TAG_PREFIX)
            }
            created = skipped = 0
            for row in pool:
                marker = f'{TAG_PREFIX}{row["question_id"]}'
                topic = topics.get(index[(row['subject'], row['chapter'])])
                if marker in existing or topic is None:
                    continue
                if self._create_question(tenant, course, topic, row, marker):
                    created += 1
                    existing.add(marker)
                else:
                    skipped += 1

        self.stdout.write(self.style.SUCCESS(
            f'{tenant.name} ({subdomain}): {created} question(s) created, {skipped} skipped; '
            f'tree nodes created {tree_summary["created"]}, updated {tree_summary["updated"]}.'))
        self.stdout.write(f'Tenant id: {tenant.id}  Course id: {course.id}')

    def _create_question(self, tenant, course, topic, row, marker):
        question_type = TYPE_MAP[row['question_type']]
        options = parse_options(row)
        wanted = set(correct_ids(row))
        indices = [str(index) for index, option in enumerate(options) if option['id'] in wanted]
        numerical = None
        if question_type == 'numerical':
            raw = str(row.get('answer') or '').strip()
            try:
                numerical = Decimal(raw)
            except InvalidOperation:
                return False  # ranges / non-numeric answers are left out
            correct = raw
        elif question_type == 'mcq_multi':
            correct = ','.join(indices)
        else:
            correct = indices[0] if indices else ''
        question = Question.objects.create(
            tenant=tenant, subject=topic.subject, topic=topic, question_type=question_type,
            question_text=strip_html(row.get('question')), question_html=row.get('question') or '',
            correct_answer=correct, numerical_answer=numerical,
            explanation=row.get('explanation') or '', status='published',
            tags=['eval_jee', marker, row.get('paper_id') or ''],
        )
        question.courses.set([course])
        if question_type != 'numerical':
            for order, option in enumerate(options):
                QuestionOption.objects.create(
                    tenant=tenant, question=question, option_text=option['text'],
                    is_correct=option['id'] in wanted, order=order)
        return True
```
